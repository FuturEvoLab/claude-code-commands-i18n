# Code of Conduct · 行動規範 · 行为准则

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, especially with people writing in their second or third language. Harassment, insults and personal attacks are not tolerated. Report problems privately to the maintainers through GitHub (the repository owner's profile lists contact options); reports are handled confidentially.
