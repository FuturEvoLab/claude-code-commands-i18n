/autofix-pr[prompt]

Inglés auto-fix PR ＝ corrección automática de PR

↗ Envía datos fuera

Lanza una sesión en la nube que vigila el PR de la rama actual y sube correcciones cuando falla la CI o hay comentarios de revisión. Requiere la CLI gh y sesiones en la nube.

Mejor uso

/autofix-pr corrige solo errores de lint y de tipos.

Etiquetas de seguridad

↗ Envía datos fuera: Envía la conversación, el código o comentarios a otro servicio (Anthropic, GitHub, sesiones en la nube, sitios abiertos en tu navegador) o hace push a un remoto. Comprueba primero qué se envía y adónde.
