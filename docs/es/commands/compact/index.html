/compact[instructions]

Resumir una conversación larga para liberar espacio

Inglés compact ＝ compactar, resumir

★ Empieza aquí

Resume la conversación hasta ahora para liberar espacio de contexto y sigue en la misma conversación. Puedes añadir instrucciones para indicar qué debe conservar el resumen.

Mejor uso

Después de una sesión larga: /compact conserva el esquema de la base de datos y la lista de errores pendientes.

Cuándo usarlo

  • La conversación es larga y Claude va lento u olvida cosas/context → /compact → /autocompact

Comandos relacionados · Conversación y contexto

  • /clearEmpezar una conversación nueva (la anterior se puede retomar)
  • /contextVer qué está llenando la ventana de contexto
  • /planVer primero un plan; los cambios esperan tu aprobación
  • /resumeVolver a una conversación anterior
  • /rewindDeshacer: volver atrás el código y la conversación
  • /autocompactDefine cuánto se llena la ventana de contexto antes de la compactación automática, por ejemplo 500k; auto vuelve al valor predeterminado ajustado al modelo.
  • /branchCrea una rama de la conversación en este punto y cambia a ella; la original se conserva y puedes volver con /resume.
  • /btwHace una pregunta aparte sobre la sesión actual sin añadirla a la conversación.
