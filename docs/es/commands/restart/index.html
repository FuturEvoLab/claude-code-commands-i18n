/restart

Inglés restart ＝ reiniciar

v2.1.288+

Reinicia Claude Code y retoma la sesión para aplicar una actualización instalada. Requiere Pro, Max o Ultra y una instalación nativa en macOS o Linux (no WSL).

Mejor uso

Cuando la barra inferior lo ofrece tras una actualización.

Alias

/update
