/model[model]

Cambiar de modelo

Inglés model ＝ modelo

★ Empieza aquí

Cambia de modelo y lo guarda como predeterminado para las sesiones nuevas. Sin argumento abre un selector; las flechas izquierda/derecha ajustan el esfuerzo en los modelos compatibles; pulsa s en una fila para cambiar solo en esta sesión.

Mejor uso

Usa un modelo más rápido para cambios pequeños; cambia con /model opus cuando un error se complica.

Cuándo usarlo

  • Ver un plan antes de un cambio grande/plan → /effort → /model
  • Gastar menos dinero y consumir menos uso/usage → /model → /effort → /context

Comandos relacionados · Modelo y razonamiento

  • /advisorActiva o desactiva la herramienta de asesor, que consulta a un segundo modelo en los momentos clave.
  • /effortDefine el nivel de esfuerzo: de low a xhigh, max o auto; status lo muestra.
  • /fastActiva o desactiva el modo rápido (mismo modelo, salida más rápida).
  • /output-styleMuestra los estilos de salida o cambia a uno, por ejemplo /output-style concise.
