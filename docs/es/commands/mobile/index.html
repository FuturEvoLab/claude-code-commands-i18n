/mobile

Inglés mobile ＝ móvil

Muestra un código QR para descargar la aplicación móvil de Claude.

Mejor uso

Para seguir el trabajo desde tu teléfono.

Alias

/ios · /android

Cuándo usarlo

  • Dejar el equipo y seguir en el teléfono/remote-control → /mobile → /desktop

Comandos relacionados · Nube, acceso remoto y otros dispositivos

  • /desktopContinúa la sesión en la aplicación Claude Code Desktop.
  • /remote-controlHace que esta sesión esté disponible para Remote Control desde claude.ai.
  • /remote-envElige el entorno en la nube predeterminado para las sesiones en la nube iniciadas desde la CLI.
  • /setup-bedrockConfigura con un asistente la autenticación, la región y los modelos fijos de Amazon Bedrock.
  • /setup-vertexConfigura con un asistente Agent Platform de Google Cloud.
  • /teleportTrae una sesión en la nube a esta terminal, con su rama y su conversación.
  • /web-setupConecta GitHub para las sesiones en la nube usando tus credenciales locales de gh.
