/claude-in-chrome[task]

Inglés Claude in Chrome ＝ Claude en Chrome

Habilidad↗ Envía datos fuera

Hace que Claude realice una tarea en tu navegador mediante Claude in Chrome, como probar una página o leer los registros de la consola. Requiere la integración con Chrome (por ejemplo, claude --chrome).

Mejor uso

/claude-in-chrome prueba el registro de usuarios en mi sitio local e informa de los errores.

Etiquetas de seguridad

↗ Envía datos fuera: Envía la conversación, el código o comentarios a otro servicio (Anthropic, GitHub, sesiones en la nube, sitios abiertos en tu navegador) o hace push a un remoto. Comprueba primero qué se envía y adónde.
