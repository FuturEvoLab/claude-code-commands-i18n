/loop[interval] [prompt]

Repetir un prompt cada cierto tiempo

Inglés loop ＝ bucle, repetir

★ Empieza aquíHabilidad

Ejecuta un prompt una y otra vez mientras la sesión sigue abierta. Si omites el intervalo, Claude marca su propio ritmo; si omites el prompt, ejecuta el prompt de mantenimiento integrado o tu loop.md.

Mejor uso

/loop 5m comprueba si terminó el despliegue. Para ejecuciones que sigan con el equipo apagado, usa /schedule.

Alias

/proactive

Cuándo usarlo

  • Repetir una tarea o ejecutarla según un horario/loop → /schedule → /goal
