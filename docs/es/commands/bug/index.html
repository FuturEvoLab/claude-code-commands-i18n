/bug[report]

Inglés bug ＝ error, fallo

↗ Envía datos fuera⚿ Puede exponer secretos

Informa de un error o comparte tu conversación; tú eliges cuánto historial incluir y confirmas antes de que se envíe nada.

Mejor uso

Cuando el propio Claude Code se comporta mal.

Alias

/share

Etiquetas de seguridad

↗ Envía datos fuera: Envía la conversación, el código o comentarios a otro servicio (Anthropic, GitHub, sesiones en la nube, sitios abiertos en tu navegador) o hace push a un remoto. Comprueba primero qué se envía y adónde.

⚿ Puede exponer secretos: La salida (archivos, portapapeles, informes) puede contener texto de la conversación, claves, contraseñas o datos personales. Revísala y elimina lo sensible antes de compartirla.

Cuándo usarlo

  • El propio Claude Code funciona mal/doctor → /status → /debug → /bug

Comandos relacionados · Diagnóstico y comentarios

  • /doctorHacer un chequeo cuando algo falla
  • /helpVer la ayuda y todos los comandos
  • /powerupAprender funciones con lecciones interactivas
  • /debugActiva el registro de depuración desde este momento y busca el problema leyendo el registro de depuración de la sesión.
  • /exitSale de la CLI.
  • /feedbackEnvía comentarios sobre el producto con el mismo diálogo y el mismo paso de consentimiento que /bug.
  • /heapdumpEscribe en el Escritorio una instantánea del heap y un desglose de la memoria para diagnosticar un uso alto de memoria.
  • /release-notesMuestra el registro de cambios en un selector de versiones; las notas aparecen sin entrar en el contexto de Claude.
