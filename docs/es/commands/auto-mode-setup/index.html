/auto-mode-setup

Inglés auto mode setup ＝ configuración del modo automático

⚑ Cambia la configuración de seguridad

Redacta entradas de autoMode.environment a partir de tu proyecto y tus sesiones recientes para que las revises y guardes. Tiene requisitos de versión y de plan.

Mejor uso

Cuando el modo automático bloquea una y otra vez acciones rutinarias.

Etiquetas de seguridad

⚑ Cambia la configuración de seguridad: Cambia lo que Claude puede hacer sin preguntar u otras opciones de seguridad. Permite solo acciones que entiendas y en las que confíes.
