Inglés help ＝ ayuda

★ Empieza aquí

Muestra la ayuda y los comandos disponibles.

Mejor uso

Olvidaste un comando: /help, o escribe / y unas letras.

Cuándo usarlo

  • Aprender Claude Code a fondo/powerup → /help → /insights

Comandos relacionados · Diagnóstico y comentarios

  • /doctorHacer un chequeo cuando algo falla
  • /powerupAprender funciones con lecciones interactivas
  • /bugInforma de un error o comparte tu conversación; tú eliges cuánto historial incluir y confirmas antes de que se envíe nada.
  • /debugActiva el registro de depuración desde este momento y busca el problema leyendo el registro de depuración de la sesión.
  • /exitSale de la CLI.
  • /feedbackEnvía comentarios sobre el producto con el mismo diálogo y el mismo paso de consentimiento que /bug.
  • /heapdumpEscribe en el Escritorio una instantánea del heap y un desglose de la memoria para diagnosticar un uso alto de memoria.
  • /release-notesMuestra el registro de cambios en un selector de versiones; las notas aparecen sin entrar en el contexto de Claude.
