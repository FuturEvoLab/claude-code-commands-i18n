/rewind

Deshacer: volver atrás el código y la conversación

Inglés rewind ＝ rebobinar

★ Empieza aquí⇄ Cambios amplios en archivos

Devuelve la conversación, el código o ambos a un punto de control anterior, o resume a partir de un mensaje que elijas.

Mejor uso

Claude rompió varios archivos: ejecuta /rewind, elige el mensaje anterior a los cambios y restaura el código y la conversación.

Alias

/checkpoint · /undo

Etiquetas de seguridad

⇄ Cambios amplios en archivos: Puede cambiar o revertir muchos archivos a la vez. Haz commit o una copia de seguridad antes, y revisa con /diff después.

Cuándo usarlo

  • Claude rompió algo y quiero deshacerlo/rewind → /diff

Comandos relacionados · Conversación y contexto

  • /clearEmpezar una conversación nueva (la anterior se puede retomar)
  • /compactResumir una conversación larga para liberar espacio
  • /contextVer qué está llenando la ventana de contexto
  • /planVer primero un plan; los cambios esperan tu aprobación
  • /resumeVolver a una conversación anterior
  • /autocompactDefine cuánto se llena la ventana de contexto antes de la compactación automática, por ejemplo 500k; auto vuelve al valor predeterminado ajustado al modelo.
  • /branchCrea una rama de la conversación en este punto y cambia a ella; la original se conserva y puedes volver con /resume.
  • /btwHace una pregunta aparte sobre la sesión actual sin añadirla a la conversación.
