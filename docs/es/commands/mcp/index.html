/mcp[reconnect (<server>|all)|enable|disable [<server>|all]]

Gestionar conexiones con herramientas externas

Inglés MCP (Model Context Protocol) ＝ MCP (Model Context Protocol, estándar para conectar herramientas externas)

★ Empieza aquí

Gestiona las conexiones a servidores MCP y OAuth. Sin argumento abre la lista; reconnect, enable o disable con el nombre de un servidor o all actúan directamente.

Mejor uso

Un conector falló o necesita autenticación: /mcp reconnect all.

Cuándo usarlo

  • Conectar herramientas o añadir nuevas capacidades/mcp → /plugin → /skills
