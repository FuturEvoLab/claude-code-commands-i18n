/rate-limit-options

Inglés rate limit options ＝ opciones ante el límite de uso

Muestra formas de seguir trabajando cuando un límite de claude.ai te bloquea: esperar y continuar automáticamente, añadir créditos de uso o mejorar el plan. Requiere una suscripción a claude.ai.

Mejor uso

El límite te bloqueó por la noche: elige continuar automáticamente cuando se restablezca.
