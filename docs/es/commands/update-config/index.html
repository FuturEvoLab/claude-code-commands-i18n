/update-config[request]

Inglés update config ＝ actualizar la configuración

Habilidad⚑ Cambia la configuración de seguridad

Describe un cambio de configuración (permitir un comando, definir una variable de entorno, añadir un hook) y Claude edita el settings.json correspondiente. Usa /config para el tema y el modelo.

Mejor uso

/update-config ejecuta prettier después de cada edición de archivo.

Etiquetas de seguridad

⚑ Cambia la configuración de seguridad: Cambia lo que Claude puede hacer sin preguntar u otras opciones de seguridad. Permite solo acciones que entiendas y en las que confíes.
