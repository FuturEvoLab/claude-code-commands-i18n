/plugin-authoring

Inglés plugin authoring ＝ creación de complementos

Habilidadv2.1.287+

Carga la referencia para escribir un mod. Es una habilidad de un complemento integrado, que puedes desactivar en /plugin.

Mejor uso

Cuando quieres un pequeño panel lateral que se quede junto al chat.

Comandos relacionados · Complementos, habilidades e integraciones

  • /mcpGestionar conexiones con herramientas externas
  • /chromeConfigura los ajustes de Claude in Chrome.
  • /claude-apiCarga la referencia de la API de Claude y de Managed Agents para el lenguaje de tu proyecto; se activa sola cuando el código importa anthropic.
  • /claude-in-chromeHace que Claude realice una tarea en tu navegador mediante Claude in Chrome, como probar una página o leer los registros de la consola.
  • /ideGestiona las integraciones con IDE y muestra su estado.
  • /install-github-appInstala la Claude GitHub App en un repositorio y, si quieres, configura flujos de trabajo y secretos de GitHub Actions.
  • /install-slack-appInstala la app de Claude para Slack mediante un flujo OAuth en el navegador.
  • /pluginGestiona complementos.
