/hooks

Inglés hooks ＝ hooks (scripts que se ejecutan solos en momentos fijos)

Muestra la configuración de los hooks.

Mejor uso

Revisa qué hay configurado cuando un hook parece romper cada cambio.

Comandos relacionados · Permisos y seguridad

  • /permissionsDecidir qué puede hacer Claude sin preguntar
  • /auto-mode-setupRedacta entradas de autoMode.environment a partir de tu proyecto y tus sesiones recientes para que las revises y guardes.
  • /fewer-permission-promptsRevisa las transcripciones en busca de llamadas comunes de solo lectura a Bash y MCP, y añade una lista de permitidos priorizada al .claude/settings.json del proyecto.
  • /privacy-settingsMuestra y actualiza la configuración de privacidad.
  • /sandboxActiva o desactiva el modo sandbox, solo en plataformas compatibles.
  • /update-configDescribe un cambio de configuración (permitir un comando, definir una variable de entorno, añadir un hook) y Claude edita el settings.json correspondiente.
