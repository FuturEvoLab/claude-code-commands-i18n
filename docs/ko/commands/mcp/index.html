/mcp[reconnect (<server>|all)|enable|disable [<server>|all]]

외부 도구 연결 관리

영어 MCP (Model Context Protocol) ＝ MCP (Model Context Protocol, 외부 도구 연결 표준)

★ 여기서 시작

MCP 서버 연결과 OAuth를 관리합니다. 인수 없이 실행하면 목록이 열리고, reconnect, enable, disable에 서버 이름이나 all을 붙이면 바로 실행합니다.

추천 사용법

커넥터가 실패했거나 인증이 필요할 때: /mcp reconnect all.

이런 상황에서 사용

  • 도구를 연결하거나 새 기능을 추가하고 싶어요/mcp → /plugin → /skills

관련 명령어 · 플러그인, 스킬, 연동

  • /chromeClaude in Chrome 설정을 구성합니다.
  • /claude-api프로젝트 언어에 맞는 Claude API와 Managed Agents 참고 자료를 불러옵니다.
  • /claude-in-chromeClaude in Chrome을 통해 브라우저에서 Claude가 작업을 수행하게 합니다.
  • /ideIDE 연동을 관리하고 상태를 보여 줍니다.
  • /install-github-app저장소에 Claude GitHub App을 설치하고, 원하면 GitHub Actions 워크플로와 시크릿도 설정합니다.
  • /install-slack-app브라우저 OAuth 과정을 통해 Claude Slack 앱을 설치합니다.
  • /plugin플러그인을 관리합니다.
  • /plugin-authoringmod(확장) 작성용 참고 자료를 불러옵니다.
