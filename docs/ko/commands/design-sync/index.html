/design-sync[hint]

영어 design sync ＝ 디자인 동기화

스킬↗ 외부로 데이터 전송

저장소의 React 디자인 시스템을 변환해 Claude Design에 업로드하여, 디자인에 실제 컴포넌트가 쓰이게 합니다. 큰 저장소에서는 첫 동기화에 몇 시간이 걸릴 수 있습니다. 대상은 독립된 claude.ai/design 사이트이며, 이 사이트는 2026년 12월 14일까지 종료됩니다.

추천 사용법

/design-sync Acme DS (위의 종료 날짜에 주의하세요).

안전 표시

↗ 외부로 데이터 전송: 대화, 코드, 댓글을 다른 서비스(Anthropic, GitHub, 클라우드 세션, 브라우저 안의 사이트)로 보내거나 원격 저장소에 푸시합니다. 무엇이 어디로 가는지 먼저 확인하세요.

관련 명령어 · 아티팩트, 슬라이드, 디자인

  • /artifact-capabilities커넥터 호출이나 다운로드 제공 같은 아티팩트 실행 기능에 대한 참고 자료와, 내 계정에서 쓸 수 있는 기능을 불러옵니다.
  • /artifact-diagramming아티팩트용 다이어그램 안내를 불러옵니다: 다이어그램이 도움이 되는 경우, 무엇을 그릴지, 밝은 테마와 어두운 테마 모두에서 잘 보이는 SVG.
  • /artifacts내가 소유하거나 공유받은 아티팩트를 나열하고, 하나를 연결하거나, 열거나, 링크를 복사합니다.
  • /dataviz차트 디자인 안내: 차트 형태를 고르고, 역할에 따라 색을 지정하며, 함께 제공되는 스크립트로 색맹 안전성과 대비를 기준으로 팔레트를 검증합니다.
  • /designUI 목업, 화면 흐름, 랜딩 페이지, 포스터를 하나의 캔버스 위 아트보드로 초안 작성합니다(Claude Design 아티팩트).
  • /design consentClaude의 Claude Design 접근을 허용하거나 철회합니다.
  • /design-login/design-sync나 /design consent가 요청할 때, claude.ai 계정으로 /design-sync의 디자인 시스템 접근을 승인합니다.
  • /slides요청 내용을 바탕으로 Claude Slides 아티팩트를 만듭니다.
