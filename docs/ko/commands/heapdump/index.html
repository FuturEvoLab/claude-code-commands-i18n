/heapdump

영어 heap dump ＝ 힙 덤프 (메모리 기록)

⚿ 비밀 정보 노출 가능

메모리 사용량이 높을 때 진단할 수 있도록 힙 스냅샷과 메모리 내역을 바탕 화면(Desktop 폴더)에 저장합니다. -diagnostics.json만 공유하세요. .heapsnapshot에는 대화 내용과 인증 정보가 들어 있습니다. 메뉴에는 보이지 않습니다.

추천 사용법

메모리 사용량이 폭증했을 때 신고용으로.

안전 표시

⚿ 비밀 정보 노출 가능: 결과물(파일, 클립보드, 보고서)에 대화 내용, 키, 비밀번호, 개인정보가 들어 있을 수 있습니다. 공유하기 전에 검토하고 민감한 부분은 가리거나 지우세요.

관련 명령어 · 진단과 피드백

  • /doctor문제가 생겼을 때 점검 실행

  • /debug지금부터 디버그 로그를 켜고, 세션 디버그 로그를 읽어 문제를 해결합니다.
  • /exitCLI를 종료합니다.
  • /feedback/bug와 같은 대화상자와 동의 단계를 거쳐 제품 피드백을 보냅니다.
