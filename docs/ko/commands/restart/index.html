/restart

영어 restart ＝ 재시작

v2.1.288 이상

설치된 업데이트를 적용하기 위해 Claude Code를 재시작하고 세션을 이어갑니다. Pro, Max 또는 Ultra와 macOS·Linux 네이티브 설치(WSL 제외)가 필요합니다.

추천 사용법

업데이트 후 하단에 안내가 나올 때.

별칭

/update

관련 명령어 · 진단과 피드백

  • /doctor문제가 생겼을 때 점검 실행
  • /help도움말과 전체 명령 보기
  • /powerup대화형 레슨으로 기능 배우기
  • /bug버그를 신고하거나 대화를 공유합니다.
  • /debug지금부터 디버그 로그를 켜고, 세션 디버그 로그를 읽어 문제를 해결합니다.
  • /exitCLI를 종료합니다.
  • /feedback/bug와 같은 대화상자와 동의 단계를 거쳐 제품 피드백을 보냅니다.
  • /heapdump메모리 사용량이 높을 때 진단할 수 있도록 힙 스냅샷과 메모리 내역을 바탕 화면(Desktop 폴더)에 저장합니다.
