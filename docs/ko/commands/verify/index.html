/verify

영어 verify ＝ 검증

스킬

테스트나 타입 검사에만 의존하지 않고, 앱을 빌드하고 실행해서 직접 보며 변경이 제대로 동작하는지 확인합니다. 직접 실행했을 때만 동작합니다.

추천 사용법

버튼 동작을 바꿨다면: /verify로 실제로 버튼을 눌러 보게 합니다.

이런 상황에서 사용

  • 커밋이나 배포 전에 점검하고 싶어요/diff → /code-review → /security-review → /verify

관련 명령어 · 리뷰와 검증

  • /code-review커밋 전에 버그 검사, 필요하면 수정까지
  • /run프로젝트의 앱을 실행하고 조작해서 변경이 동작하는 모습을 확인합니다.
  • /run-skill-generator깨끗한 환경에서 앱을 빌드, 실행, 조작하는 방법을 /run과 /verify에 알려 주는 프로젝트 전용 스킬을 작성합니다.
  • /security-review현재 브랜치와 origin 기본 브랜치의 diff를 분석해 인젝션, 인증 문제, 데이터 노출 같은 취약점을 찾습니다.
  • /simplify에이전트 4개가 병렬로 변경된 코드를 재사용, 단순화, 효율, 추상화 수준 관점에서 검토한 뒤 수정을 적용합니다.
  • /ultrareview클라우드 샌드박스에서 여러 에이전트가 심층 리뷰를 합니다.
