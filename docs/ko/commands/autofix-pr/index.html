/autofix-pr[prompt]

영어 auto-fix PR ＝ PR 자동 수정

↗ 외부로 데이터 전송

현재 브랜치의 PR을 지켜보다가 CI 실패나 리뷰 댓글이 생기면 수정을 푸시하는 클라우드 세션을 시작합니다. gh CLI와 클라우드 세션이 필요합니다.

추천 사용법

/autofix-pr lint와 타입 오류만 고쳐 줘.

안전 표시

↗ 외부로 데이터 전송: 대화, 코드, 댓글을 다른 서비스(Anthropic, GitHub, 클라우드 세션, 브라우저 안의 사이트)로 보내거나 원격 저장소에 푸시합니다. 무엇이 어디로 가는지 먼저 확인하세요.

관련 명령어 · 자동화와 예약

  • /loop일정 간격으로 프롬프트 반복
  • /deep-research웹 검색을 여러 갈래로 수행하고, 출처를 가져와 교차 확인한 뒤, 출처가 달린 보고서를 쓰는 기본 제공 워크플로입니다.
  • /schedule안내형 대화를 통해 클라우드 예약 작업(이전 이름: routines)을 만들고, 수정하고, 나열하고, 실행합니다.
