/import[codex|gemini|cursor] [--dry-run] [--yes]

영어 import ＝ 가져오기

⇄ 파일을 대량 변경

OpenAI Codex, Gemini CLI, Cursor에서 지침 파일, MCP 서버, 명령, 서브에이전트, 스킬을 가져옵니다. --dry-run은 미리 보기만 합니다. 일부 클라우드 제공업체에서는 사용할 수 없고, Cursor 가져오기는 v2.1.265 이상이 필요합니다.

추천 사용법

Cursor에서 옮겨 올 때: 먼저 /import cursor --dry-run으로 확인한 뒤 실제로 가져옵니다.

안전 표시

⇄ 파일을 대량 변경: 한 번에 많은 파일을 바꾸거나 되돌릴 수 있습니다. 먼저 커밋하거나 백업하고, 실행 후에는 /diff로 검토하세요.

관련 명령어 · 프로젝트와 파일

  • /init프로젝트의 CLAUDE.md 만들기
  • /add-dir이동하지 않고 이 세션에서 파일에 접근할 작업 폴더를 추가합니다.
  • /cd대화를 유지한 채 세션을 새 작업 폴더로 옮깁니다.
  • /diff작업 트리의 변경 사항을 검토합니다.
  • /insights이 컴퓨터의 최근 세션을 HTML 보고서로 만들어 줍니다: 프로젝트, 사용 습관, 자주 막히는 곳, 써 볼 만한 기능.
  • /team-onboarding최근 30일간의 세션, 명령, MCP 사용 내역을 분석해서, 새 팀원이 첫 메시지로 붙여 넣을 수 있는 Markdown 가이드를 작성합니다.
