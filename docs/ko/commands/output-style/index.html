/output-style[style]

영어 output style ＝ 출력 스타일

v2.1.269 이상

출력 스타일 목록을 보여 주거나 하나로 바꿉니다. 예: /output-style concise.

추천 사용법

먼저 인수 없이 /output-style을 실행해 무엇이 있는지 보고, 하나를 고릅니다(예: 더 간결한 스타일).

관련 명령어 · 모델과 추론

  • /model모델 바꾸기
  • /advisor중요한 순간에 두 번째 모델에게 의견을 묻는 advisor 도구를 켜거나 끕니다.
  • /effort노력 수준을 정합니다: low부터 xhigh까지의 단계, max, auto 중 하나.
  • /fast빠른 모드를 켜고 끕니다(같은 모델, 더 빠른 출력).
