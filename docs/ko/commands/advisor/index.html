/advisor[model|off]

영어 advisor ＝ 조언자

중요한 순간에 두 번째 모델에게 의견을 묻는 advisor 도구를 켜거나 끕니다. fable, opus, sonnet 또는 전체 모델 ID를 받습니다(fable은 접근 권한이 필요). 인수 없이 실행하면 선택 화면이 열립니다.

추천 사용법

평소에는 빠른 모델로 작업하고, 중요한 판단에서만 더 강한 모델의 의견을 받을 때: /advisor opus.

관련 명령어 · 모델과 추론

  • /model모델 바꾸기
  • /effort노력 수준을 정합니다: low부터 xhigh까지의 단계, max, auto 중 하나.
  • /fast빠른 모드를 켜고 끕니다(같은 모델, 더 빠른 출력).
  • /output-style출력 스타일 목록을 보여 주거나 하나로 바꿉니다.
