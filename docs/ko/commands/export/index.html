/export[filename]

영어 export ＝ 내보내기

⚿ 비밀 정보 노출 가능

대화를 일반 텍스트로 내보냅니다. 이름을 주면 바로 파일로 저장하고, 아니면 복사/저장 대화상자를 엽니다.

추천 사용법

도움이 된 디버깅 기록을 보관할 때: /export 디버깅-기록.txt.

안전 표시

⚿ 비밀 정보 노출 가능: 결과물(파일, 클립보드, 보고서)에 대화 내용, 키, 비밀번호, 개인정보가 들어 있을 수 있습니다. 공유하기 전에 검토하고 민감한 부분은 가리거나 지우세요.

관련 명령어 · 대화와 컨텍스트

  • /clear새 대화 시작 (이전 대화는 다시 열 수 있음)
  • /compact긴 대화를 요약해 공간 확보
  • /context컨텍스트를 무엇이 채우는지 보기
  • /plan먼저 계획부터, 수정은 승인 후에
  • /resume이전 대화로 돌아가기
  • /rewind되돌리기: 코드와 대화를 이전으로
  • /autocompact컨텍스트 창이 얼마나 찼을 때 자동 압축할지 정합니다.
  • /branch이 지점에서 대화를 분기하고 그쪽으로 전환합니다.
