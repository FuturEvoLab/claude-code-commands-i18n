/install-github-app

영어 install GitHub app ＝ GitHub 앱 설치

↗ 외부로 데이터 전송⚑ 안전 설정 변경

저장소에 Claude GitHub App을 설치하고, 원하면 GitHub Actions 워크플로와 시크릿도 설정합니다. github.com 전용입니다.

추천 사용법

이슈와 PR에서 Claude를 멘션해 그곳에서 작업하게 하고 싶을 때.

안전 표시

↗ 외부로 데이터 전송: 대화, 코드, 댓글을 다른 서비스(Anthropic, GitHub, 클라우드 세션, 브라우저 안의 사이트)로 보내거나 원격 저장소에 푸시합니다. 무엇이 어디로 가는지 먼저 확인하세요.

⚑ 안전 설정 변경: Claude가 묻지 않고 할 수 있는 일이나 다른 안전 관련 설정을 바꿉니다. 이해하고 신뢰하는 작업만 허용하세요.

관련 명령어 · 플러그인, 스킬, 연동

  • /mcp외부 도구 연결 관리
  • /chromeClaude in Chrome 설정을 구성합니다.
  • /claude-api프로젝트 언어에 맞는 Claude API와 Managed Agents 참고 자료를 불러옵니다.
  • /claude-in-chromeClaude in Chrome을 통해 브라우저에서 Claude가 작업을 수행하게 합니다.
  • /ideIDE 연동을 관리하고 상태를 보여 줍니다.
  • /install-slack-app브라우저 OAuth 과정을 통해 Claude Slack 앱을 설치합니다.
  • /plugin플러그인을 관리합니다.
  • /plugin-authoringmod(확장) 작성용 참고 자료를 불러옵니다.
