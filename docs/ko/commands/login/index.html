/login

영어 log in ＝ 로그인

Anthropic 계정에 로그인합니다.

추천 사용법

새 컴퓨터를 쓸 때나 세션이 만료되었을 때.

관련 명령어 · 계정과 사용량

  • /usage비용과 플랜 한도 확인
  • /logoutAnthropic 계정에서 로그아웃합니다.
  • /passes친구에게 Claude Code 무료 1주일 이용권을 공유합니다.
  • /rate-limit-optionsclaude.ai 한도에 걸려 작업이 막혔을 때 계속하는 방법을 보여 줍니다: 기다렸다가 자동으로 이어서 하기, 사용량 크레딧 추가, 업그레이드.
  • /status설정 화면의 Status 탭을 엽니다: 버전, 모델, 계정, 연결 상태.
  • /upgrade브라우저에서 업그레이드 페이지를 엽니다.
  • /usage-credits사용량 크레딧을 설정하거나 요청합니다.
