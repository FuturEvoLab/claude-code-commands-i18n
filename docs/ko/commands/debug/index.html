/debug[description]

영어 debug ＝ 디버그

스킬

지금부터 디버그 로그를 켜고, 세션 디버그 로그를 읽어 문제를 해결합니다. 문제 내용을 설명할 수도 있습니다.

추천 사용법

/debug MCP 서버 연결이 계속 실패해.

이런 상황에서 사용

  • Claude Code 자체가 이상하게 동작해요/doctor → /status → /debug → /bug

관련 명령어 · 진단과 피드백

  • /doctor문제가 생겼을 때 점검 실행
  • /help도움말과 전체 명령 보기
  • /powerup대화형 레슨으로 기능 배우기
  • /bug버그를 신고하거나 대화를 공유합니다.
  • /exitCLI를 종료합니다.
  • /feedback/bug와 같은 대화상자와 동의 단계를 거쳐 제품 피드백을 보냅니다.
  • /heapdump메모리 사용량이 높을 때 진단할 수 있도록 힙 스냅샷과 메모리 내역을 바탕 화면(Desktop 폴더)에 저장합니다.
  • /release-notes버전 선택 화면에서 변경 내역을 봅니다.
