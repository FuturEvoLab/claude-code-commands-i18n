/setup-bedrock

영어 set up Bedrock ＝ Bedrock 설정

마법사를 통해 Amazon Bedrock 인증, 리전, 모델 고정을 설정합니다. CLAUDE_CODE_USE_BEDROCK=1을 설정하기 전에는 메뉴에 보이지 않으니 전체 이름을 직접 입력하세요.

추천 사용법

회사에서 AWS를 통해 Claude를 쓸 때.

관련 명령어 · 클라우드, 원격, 다른 기기

  • /desktopClaude Code Desktop 앱에서 세션을 이어갑니다.
  • /mobileClaude 모바일 앱을 내려받을 수 있는 QR 코드를 보여 줍니다.
  • /remote-control이 세션을 claude.ai에서 Remote Control로 조작할 수 있게 합니다.
  • /remote-envCLI에서 시작하는 클라우드 세션의 기본 클라우드 환경을 고릅니다.
  • /setup-vertex마법사를 통해 Google Cloud의 Agent Platform을 설정합니다.
  • /teleport클라우드 세션을 이 터미널로 가져오고, 그 브랜치와 대화를 받아옵니다.
  • /web-setup로컬 gh 인증 정보를 사용해 클라우드 세션용 GitHub를 연결합니다.
