/autocompact[auto|<tokens>]

영어 auto compact ＝ 자동 압축

v2.1.221 이상

컨텍스트 창이 얼마나 찼을 때 자동 압축할지 정합니다. 예: 500k. auto는 모델에 맞춘 기본값으로 되돌립니다. 사용자 설정에 저장되고 바로 적용됩니다.

추천 사용법

긴 작업이 잦은 압축으로 끊길 때: /autocompact 500k.

이런 상황에서 사용

  • 대화가 길어져서 Claude가 느리거나 자꾸 잊어버려요/context → /compact → /autocompact

관련 명령어 · 대화와 컨텍스트

  • /clear새 대화 시작 (이전 대화는 다시 열 수 있음)
  • /compact긴 대화를 요약해 공간 확보
  • /context컨텍스트를 무엇이 채우는지 보기
  • /plan먼저 계획부터, 수정은 승인 후에
  • /resume이전 대화로 돌아가기
  • /rewind되돌리기: 코드와 대화를 이전으로
  • /branch이 지점에서 대화를 분기하고 그쪽으로 전환합니다.
  • /btw현재 세션에 대해 곁가지 질문을 하되, 그 내용을 대화에는 추가하지 않습니다.
