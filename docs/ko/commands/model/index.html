/model[model]

모델 바꾸기

영어 model ＝ 모델

★ 여기서 시작

모델을 바꾸고 새 세션의 기본값으로 저장합니다. 인수 없이 실행하면 선택 화면이 열립니다. 지원되는 모델에서는 좌우 키로 노력 수준을 조절하고, 행에서 s를 누르면 이 세션에서만 바꿉니다.

추천 사용법

작은 수정은 빠른 모델로 하고, 버그가 어려워지면 /model opus로 바꿉니다.

이런 상황에서 사용

  • 큰 변경 전에 계획부터 보고 싶어요/plan → /effort → /model
  • 비용과 사용량을 줄이고 싶어요/usage → /model → /effort → /context

관련 명령어 · 모델과 추론

  • /advisor중요한 순간에 두 번째 모델에게 의견을 묻는 advisor 도구를 켜거나 끕니다.
  • /effort노력 수준을 정합니다: low부터 xhigh까지의 단계, max, auto 중 하나.
  • /fast빠른 모드를 켜고 끕니다(같은 모델, 더 빠른 출력).
  • /output-style출력 스타일 목록을 보여 주거나 하나로 바꿉니다.
