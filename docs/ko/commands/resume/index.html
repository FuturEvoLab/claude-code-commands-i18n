/resume[session]

이전 대화로 돌아가기

영어 resume ＝ 재개·이어서 하기

★ 여기서 시작

ID나 이름으로 대화를 다시 열거나, 세션 선택 화면을 엽니다. 백그라운드 세션에는 bg 표시가 붙습니다.

추천 사용법

어제 작업 도중 노트북을 닫았다면: /resume으로 어제 대화를 골라 이어서 합니다.

별칭

/continue

이런 상황에서 사용

  • 관계없는 작업을 처음부터 시작하고 싶어요/clear → /resume
  • 어제 끝내지 못한 작업을 이어서 하고 싶어요/resume → /rename → /recap

관련 명령어 · 대화와 컨텍스트

  • /clear새 대화 시작 (이전 대화는 다시 열 수 있음)
  • /compact긴 대화를 요약해 공간 확보
  • /context컨텍스트를 무엇이 채우는지 보기
  • /plan먼저 계획부터, 수정은 승인 후에
  • /rewind되돌리기: 코드와 대화를 이전으로
  • /autocompact컨텍스트 창이 얼마나 찼을 때 자동 압축할지 정합니다.
  • /branch이 지점에서 대화를 분기하고 그쪽으로 전환합니다.
  • /btw현재 세션에 대해 곁가지 질문을 하되, 그 내용을 대화에는 추가하지 않습니다.
