/usage

비용과 플랜 한도 확인

영어 usage ＝ 사용량

★ 여기서 시작

세션 비용, 오늘·이번 주·이번 달 지출, 플랜 사용 한도, 활동 통계를 보여 줍니다. 구독 플랜에서 무엇이 한도에 포함되는지도 표시합니다. /stats는 Stats 탭을 엽니다. 경고마다 원인과 한 줄 해결책이 표시되며, f를 누르면 해결책이 적용됩니다.

추천 사용법

더 저렴한 모델로 바꿀지 정하기 전에 /usage를 확인합니다.

별칭

/cost · /stats

이런 상황에서 사용

  • 비용과 사용량을 줄이고 싶어요/usage → /model → /effort → /context

관련 명령어 · 계정과 사용량

  • /loginAnthropic 계정에 로그인합니다.
  • /logoutAnthropic 계정에서 로그아웃합니다.
  • /passes친구에게 Claude Code 무료 1주일 이용권을 공유합니다.
  • /rate-limit-optionsclaude.ai 한도에 걸려 작업이 막혔을 때 계속하는 방법을 보여 줍니다: 기다렸다가 자동으로 이어서 하기, 사용량 크레딧 추가, 업그레이드.
  • /status설정 화면의 Status 탭을 엽니다: 버전, 모델, 계정, 연결 상태.
  • /upgrade브라우저에서 업그레이드 페이지를 엽니다.
  • /usage-credits사용량 크레딧을 설정하거나 요청합니다.
