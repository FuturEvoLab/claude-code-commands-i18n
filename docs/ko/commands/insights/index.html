/insights

영어 insights ＝ 인사이트·분석

이 컴퓨터의 최근 세션을 HTML 보고서로 만들어 줍니다: 프로젝트, 사용 습관, 자주 막히는 곳, 써 볼 만한 기능. 클라우드 세션에서는 사용할 수 없습니다.

추천 사용법

몇 주 사용한 뒤 /insights로 아직 써 보지 않은 기능을 찾아봅니다.

이런 상황에서 사용

  • Claude Code를 제대로 배우고 싶어요/powerup → /help → /insights

관련 명령어 · 프로젝트와 파일

  • /init프로젝트의 CLAUDE.md 만들기
  • /add-dir이동하지 않고 이 세션에서 파일에 접근할 작업 폴더를 추가합니다.
  • /cd대화를 유지한 채 세션을 새 작업 폴더로 옮깁니다.
  • /diff작업 트리의 변경 사항을 검토합니다.
  • /importOpenAI Codex, Gemini CLI, Cursor에서 지침 파일, MCP 서버, 명령, 서브에이전트, 스킬을 가져옵니다.
  • /team-onboarding최근 30일간의 세션, 명령, MCP 사용 내역을 분석해서, 새 팀원이 첫 메시지로 붙여 넣을 수 있는 Markdown 가이드를 작성합니다.
