/loop[interval] [prompt]

일정 간격으로 프롬프트 반복

영어 loop ＝ 반복

★ 여기서 시작스킬

세션이 열려 있는 동안 프롬프트를 반복해서 실행합니다. 간격을 생략하면 Claude가 스스로 속도를 정하고, 프롬프트를 생략하면 기본 제공 유지 관리 프롬프트나 loop.md를 실행합니다.

추천 사용법

/loop 5m 배포가 끝났는지 확인해 줘. 컴퓨터가 꺼져 있어도 계속 실행하려면 /schedule을 사용하세요.

별칭

/proactive

이런 상황에서 사용

  • 작업을 반복하거나 예약해서 실행하고 싶어요/loop → /schedule → /goal

관련 명령어 · 자동화와 예약

  • /autofix-pr현재 브랜치의 PR을 지켜보다가 CI 실패나 리뷰 댓글이 생기면 수정을 푸시하는 클라우드 세션을 시작합니다.
  • /deep-research웹 검색을 여러 갈래로 수행하고, 출처를 가져와 교차 확인한 뒤, 출처가 달린 보고서를 쓰는 기본 제공 워크플로입니다.
  • /schedule안내형 대화를 통해 클라우드 예약 작업(이전 이름: routines)을 만들고, 수정하고, 나열하고, 실행합니다.
