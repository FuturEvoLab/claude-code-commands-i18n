/effort[level|auto|status|ultracode [on|off]]

영어 effort ＝ 노력 수준 (추론의 깊이)

노력 수준을 정합니다: low부터 xhigh까지의 단계, max, auto 중 하나. status는 현재 값을 표시합니다. max는 이 세션에서만 유효합니다. ultracode on|off로 ultracode를 켜고 끕니다.

추천 사용법

재현이 어려운 버그를 찾을 때: /effort high, 오타만 고칠 때: /effort low.

이런 상황에서 사용

  • 큰 변경 전에 계획부터 보고 싶어요/plan → /effort → /model
  • 비용과 사용량을 줄이고 싶어요/usage → /model → /effort → /context

관련 명령어 · 모델과 추론

  • /model모델 바꾸기
  • /advisor중요한 순간에 두 번째 모델에게 의견을 묻는 advisor 도구를 켜거나 끕니다.
  • /fast빠른 모드를 켜고 끕니다(같은 모델, 더 빠른 출력).
  • /output-style출력 스타일 목록을 보여 주거나 하나로 바꿉니다.
