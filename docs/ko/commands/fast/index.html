/fast[on|off]

영어 fast ＝ 빠르게

빠른 모드를 켜고 끕니다(같은 모델, 더 빠른 출력). 응답 도중에도 바꿀 수 있으며, 진행 중인 턴은 원래 속도로 끝납니다. 요금은 공식 빠른 모드 문서를 확인하세요.

추천 사용법

시간이 촉박할 때: /fast on, 그렇지 않을 때: /fast off.

관련 명령어 · 모델과 추론

  • /model모델 바꾸기
  • /advisor중요한 순간에 두 번째 모델에게 의견을 묻는 advisor 도구를 켜거나 끕니다.
  • /effort노력 수준을 정합니다: low부터 xhigh까지의 단계, max, auto 중 하나.
  • /output-style출력 스타일 목록을 보여 주거나 하나로 바꿉니다.
