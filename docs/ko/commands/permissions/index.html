/permissions

Claude가 묻지 않고 할 수 있는 일 정하기

영어 permissions ＝ 권한

★ 여기서 시작⚑ 안전 설정 변경

도구에 대한 허용, 확인, 거부 규칙을 관리합니다: 범위별로 보기, 규칙 추가·삭제, 작업 폴더 관리, 「Recently blocked」 탭(자동 모드가 막은 호출)과 분류기 규칙 검토.

추천 사용법

매번 npm test 실행을 승인하기 귀찮다면 여기서 허용합니다.

별칭

/allowed-tools

안전 표시

⚑ 안전 설정 변경: Claude가 묻지 않고 할 수 있는 일이나 다른 안전 관련 설정을 바꿉니다. 이해하고 신뢰하는 작업만 허용하세요.

이런 상황에서 사용

  • 권한 확인 요청이 너무 많아요/permissions → /fewer-permission-prompts

관련 명령어 · 권한과 안전

  • /auto-mode-setup프로젝트와 최근 세션을 바탕으로 autoMode.environment 항목 초안을 만들어, 검토 후 저장할 수 있게 합니다.
  • /fewer-permission-prompts대화 기록에서 자주 쓰는 읽기 전용 Bash 및 MCP 호출을 찾아, 우선순위가 매겨진 허용 목록을 프로젝트 .claude/settings.json에 추가합니다.
  • /hooks훅 설정을 보여 줍니다.
  • /privacy-settings개인정보 설정을 보고 변경합니다.
  • /sandbox샌드박스 모드를 켜고 끕니다.
  • /update-config설정 변경 내용(명령 허용, 환경 변수 설정, 훅 추가)을 말로 설명하면, Claude가 해당 settings.json을 편집합니다.
