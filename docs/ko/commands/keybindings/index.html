/keybindings

영어 keybindings ＝ 키 바인딩 (단축키 설정)

키보드 단축키 파일을 엽니다.

추천 사용법

익숙한 키로 동작을 다시 지정합니다.

관련 명령어 · 설정과 화면

  • /color이 세션의 프롬프트 바 색을 정합니다: red, blue, green, yellow, purple, orange, pink, cyan 중 하나.
  • /config테마, 모델, 출력 스타일 등을 바꾸는 설정 화면을 열거나, key=value 형식으로 바로 설정합니다.
  • /focus마지막 프롬프트, 한 줄짜리 도구 요약, 최종 응답만 보여 주는 화면을 켜고 끕니다.
  • /scroll-speed마우스 휠 스크롤 속도를 조절합니다.
  • /statusline상태 표시줄을 설정합니다.
  • /terminal-setupVS Code, Cursor, Devin Desktop, Alacritty, Zed에서 줄바꿈용 Shift+Enter를 설정합니다.
  • /theme색 테마를 바꿉니다: auto, 밝은 테마와 어두운 테마, 색맹 친화 테마, ANSI 테마, 사용자 지정 테마.
  • /tui터미널 렌더러를 정하고, 대화를 유지한 채 다시 실행합니다.
