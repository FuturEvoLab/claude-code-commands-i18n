/schedule[description]

영어 schedule ＝ 예약·일정

안내형 대화를 통해 클라우드 예약 작업(이전 이름: routines)을 만들고, 수정하고, 나열하고, 실행합니다. Console API 키로는 사용할 수 없습니다.

추천 사용법

/schedule 평일 매일 오전 9시에 저장소의 새 이슈를 요약해 줘.

별칭

/routines

이런 상황에서 사용

  • 작업을 반복하거나 예약해서 실행하고 싶어요/loop → /schedule → /goal

관련 명령어 · 자동화와 예약

  • /loop일정 간격으로 프롬프트 반복
  • /autofix-pr현재 브랜치의 PR을 지켜보다가 CI 실패나 리뷰 댓글이 생기면 수정을 푸시하는 클라우드 세션을 시작합니다.
  • /deep-research웹 검색을 여러 갈래로 수행하고, 출처를 가져와 교차 확인한 뒤, 출처가 달린 보고서를 쓰는 기본 제공 워크플로입니다.
