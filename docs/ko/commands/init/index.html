/init

프로젝트의 CLAUDE.md 만들기

영어 initialize ＝ 초기화

★ 여기서 시작

새 세션마다 읽는 CLAUDE.md 안내 파일로 프로젝트를 초기화합니다. Codex나 Gemini CLI 설정을 찾으면 /import를 제안합니다.

추천 사용법

새 저장소에서 가장 먼저: /init. 그다음 /memory로 내용을 다듬습니다.

이런 상황에서 사용

  • Claude가 항상 한국어로 답하게 하고 싶어요/init → /memory

관련 명령어 · 프로젝트와 파일

  • /add-dir이동하지 않고 이 세션에서 파일에 접근할 작업 폴더를 추가합니다.
  • /cd대화를 유지한 채 세션을 새 작업 폴더로 옮깁니다.
  • /diff작업 트리의 변경 사항을 검토합니다.
  • /importOpenAI Codex, Gemini CLI, Cursor에서 지침 파일, MCP 서버, 명령, 서브에이전트, 스킬을 가져옵니다.
  • /insights이 컴퓨터의 최근 세션을 HTML 보고서로 만들어 줍니다: 프로젝트, 사용 습관, 자주 막히는 곳, 써 볼 만한 기능.
  • /team-onboarding최근 30일간의 세션, 명령, MCP 사용 내역을 분석해서, 새 팀원이 첫 메시지로 붙여 넣을 수 있는 Markdown 가이드를 작성합니다.
