/workflow-authoring

영어 workflow authoring ＝ 워크플로 작성

스킬

동적 워크플로 스크립트를 작성하기 위한 참고 자료를 불러옵니다. 보통은 Claude가 알아서 불러오며, 저장된 스크립트를 직접 고치기 전에 실행하세요. 동적 워크플로가 켜진 곳에서만 쓸 수 있습니다.

추천 사용법

저장된 워크플로 스크립트를 직접 고치기 전에.

관련 명령어 · 병렬 작업과 백그라운드

  • /agents서브에이전트를 만들거나 관리하려면 Claude에게 부탁하거나 .claude/agents/를 직접 편집하라는 안내를 표시합니다.
  • /background세션을 분리해 백그라운드 에이전트로 실행하고 터미널을 비워 줍니다.
  • /batch큰 변경을 병렬로 진행합니다: 먼저 코드베이스를 조사해 작업을 독립된 단위 5~30개로 나누고 계획을 보여 줍니다.
  • /fork대화를 새 백그라운드 세션으로 복사하고, 사용자는 여기서 계속 작업할 수 있습니다.
  • /list-agentsClaude가 메시지를 보낼 수 있는 서브에이전트, 팀원, 다른 세션을 각각 부를 이름과 함께 나열합니다.
  • /stop연결된 백그라운드 세션을 정지합니다.
  • /subtask대화를 물려받는 포크된 서브에이전트를 만들고, 결과를 이곳에 보고하게 합니다.
  • /tasks이 세션의 백그라운드 작업을 보고 관리합니다.
