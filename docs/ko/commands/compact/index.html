/compact[instructions]

긴 대화를 요약해 공간 확보

영어 compact ＝ 압축

★ 여기서 시작

지금까지의 대화를 요약해서 컨텍스트 공간을 확보하고, 같은 대화를 이어갑니다. 지시를 덧붙이면 요약에 무엇을 남길지 정할 수 있습니다.

추천 사용법

긴 작업을 한 뒤: /compact 데이터베이스 구조와 미해결 버그 목록은 남겨 줘.

이런 상황에서 사용

  • 대화가 길어져서 Claude가 느리거나 자꾸 잊어버려요/context → /compact → /autocompact

관련 명령어 · 대화와 컨텍스트

  • /clear새 대화 시작 (이전 대화는 다시 열 수 있음)
  • /context컨텍스트를 무엇이 채우는지 보기
  • /plan먼저 계획부터, 수정은 승인 후에
  • /resume이전 대화로 돌아가기
  • /rewind되돌리기: 코드와 대화를 이전으로
  • /autocompact컨텍스트 창이 얼마나 찼을 때 자동 압축할지 정합니다.
  • /branch이 지점에서 대화를 분기하고 그쪽으로 전환합니다.
  • /btw현재 세션에 대해 곁가지 질문을 하되, 그 내용을 대화에는 추가하지 않습니다.
