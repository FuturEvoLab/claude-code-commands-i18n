/copy[N]

영어 copy ＝ 복사

마지막 응답을 클립보드에 복사합니다. /copy 2는 끝에서 두 번째 응답을 복사합니다. 코드 블록이 있으면 선택 화면에서 블록 하나만 복사할 수 있고, w를 누르면 대신 파일로 저장합니다(SSH 접속 중에 편리).

추천 사용법

Claude가 써 준 코드 조각이나 명령을 /copy로 복사해 필요한 곳에 붙여 넣습니다.

관련 명령어 · 대화와 컨텍스트

  • /clear새 대화 시작 (이전 대화는 다시 열 수 있음)
  • /compact긴 대화를 요약해 공간 확보
  • /context컨텍스트를 무엇이 채우는지 보기
  • /plan먼저 계획부터, 수정은 승인 후에
  • /resume이전 대화로 돌아가기
  • /rewind되돌리기: 코드와 대화를 이전으로
  • /autocompact컨텍스트 창이 얼마나 찼을 때 자동 압축할지 정합니다.
  • /branch이 지점에서 대화를 분기하고 그쪽으로 전환합니다.
