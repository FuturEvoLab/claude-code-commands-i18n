/goal[condition|clear]

영어 goal ＝ 목표

목표를 설정합니다. 조건이 충족되거나 목표가 해제될 때까지 Claude가 여러 턴에 걸쳐 계속 작업합니다. 인수 없이 실행하면 현재 목표를 보여 주고, clear(또는 stop, off 등)로 목표를 지웁니다.

추천 사용법

/goal 모든 테스트 통과로 설정하고, 테스트가 모두 통과할 때까지 반복하게 둡니다.

이런 상황에서 사용

  • 작업을 반복하거나 예약해서 실행하고 싶어요/loop → /schedule → /goal

관련 명령어 · 대화와 컨텍스트

  • /clear새 대화 시작 (이전 대화는 다시 열 수 있음)
  • /compact긴 대화를 요약해 공간 확보
  • /context컨텍스트를 무엇이 채우는지 보기
  • /plan먼저 계획부터, 수정은 승인 후에
  • /resume이전 대화로 돌아가기
  • /rewind되돌리기: 코드와 대화를 이전으로
  • /autocompact컨텍스트 창이 얼마나 찼을 때 자동 압축할지 정합니다.
  • /branch이 지점에서 대화를 분기하고 그쪽으로 전환합니다.
