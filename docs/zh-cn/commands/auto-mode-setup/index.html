/auto-mode-setup

英文 auto mode setup ＝ 自动模式设置

⚑ 会改变安全设置

根据你的项目和近期会话起草 autoMode.environment 条目，审核后保存到用户设置，帮助自动模式更准确地判断。有版本和套餐要求。

最佳用法

自动模式总是误拦你常用的操作时。

安全标记

⚑ 会改变安全设置: 会改变 Claude 无需询问就能执行的操作范围，或其他安全相关设置。只放行你理解且信任的操作。

相关命令 · 权限与安全

  • /permissions设置哪些操作可以直接做
  • /fewer-permission-prompts扫描历史记录中常用的只读 Bash 和 MCP 调用，把它们按优先级加入项目 .claude/settings.json 的允许清单。
  • /hooks查看 hook 配置。
  • /privacy-settings查看和修改隐私设置，仅限 Pro、Max、Ultra 订阅用户。
  • /sandbox开关沙箱模式，仅在支持的平台上可用。
  • /update-config用自然语言描述设置改动（允许某命令、设置环境变量、添加 hook），Claude 修改对应的 settings.json。主题、模型等用 /config。
