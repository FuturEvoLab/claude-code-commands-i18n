/mobile

英文 mobile ＝ 手机

显示下载 Claude 手机 App 的二维码。

最佳用法

想在手机上查看进度或远程操作。

同义命令

/ios · /android

适用场景

  • 离开电脑，用手机继续/remote-control → /mobile → /desktop

相关命令 · 云端、远程与其他设备

  • /desktop在 Claude Code 桌面 App 中继续当前会话。需要 macOS 或 x64 Windows 及 Claude 订阅。
  • /remote-control让本会话可以从 claude.ai（网页或手机）远程操作。需要 claude.ai 订阅。
  • /remote-env选择从命令行启动云端会话时默认使用的云端环境。
  • /setup-bedrock通过向导配置 Amazon Bedrock 的认证、区域和模型。设置 CLAUDE_CODE_USE_BEDROCK=1 之前不会出现在菜单中，需要完整输入。
  • /setup-vertex通过向导配置 Google Cloud Agent Platform 的认证、项目、区域和模型。设置 CLAUDE_CODE_USE_VERTEX=1 之前不会出现在菜单中，需要完整输入。
  • /teleport把云端会话拉到本地终端：选择后获取分支和对话。需要 claude.ai 订阅。
  • /web-setup用本地 gh 命令行的登录信息，为云端会话连接 GitHub 账号。
