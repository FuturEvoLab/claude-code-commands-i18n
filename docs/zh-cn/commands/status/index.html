/status

英文 status ＝ 状态

打开设置的「状态」页：版本、模型、账号、连接情况。Claude 回复中也能运行。

最佳用法

向别人求助前先截一张 /status 的图。

适用场景

  • Claude Code 本身出问题了/doctor → /status → /debug → /bug

相关命令 · 账号与用量

  • /usage查看费用和用量上限
  • /login登录 Anthropic 账号。
  • /logout退出 Anthropic 账号。
  • /passes把一周免费 Claude Code 分享给朋友。仅在账号符合条件时显示。
  • /rate-limit-optionsclaude.ai 用量上限阻止请求时显示选项：等待重置后自动继续、添加用量额度或升级套餐。需要 claude.ai 订阅。
  • /upgrade在浏览器打开升级套餐的页面。
  • /usage-credits达到上限时配置或申请用量额度：打开账单设置页；Team/Enterprise 无账单权限的成员则向管理员发送申请。旧名 /extra-usage。
