/autofix-pr[prompt]

英文 auto-fix PR ＝ 自动修复 PR

↗ 会发送到外部

开一个云端会话盯住当前分支的 PR，CI 失败或有人留评审意见时自动推送修复。需要 gh 命令行工具和云端会话权限。

最佳用法

只想让它修格式问题：/autofix-pr 只修 lint 和类型错误。

安全标记

↗ 会发送到外部: 会把对话、代码或评论发送到其他服务（如 Anthropic、GitHub、云端会话、浏览器中的网站），或推送到远程仓库。确认内容和目标后再运行。
