/mcp[reconnect (<server>|all)|enable|disable [<server>|all]]

管理外部工具连接

英文 MCP (Model Context Protocol) ＝ 模型上下文协议（连接外部工具的标准）

★ 新手推荐

管理 MCP 服务器连接和 OAuth 登录。不带参数打开列表；reconnect、enable、disable 加服务器名或 all 可直接操作。

最佳用法

连接器报错或需要登录：/mcp reconnect all。

适用场景

  • 连接外部工具或安装新能力/mcp → /plugin → /skills

相关命令 · 插件、技能与外部连接

  • /chrome配置 Claude in Chrome 的设置。
  • /claude-api加载与你项目语言对应的 Claude API 和 Managed Agents 资料；代码导入 anthropic 时会自动启用。子命令包括 migrate、upgrade、api-version、cost-optimize、latency-optimize、build-eval、prompt-audit、managed-agents-onboard、managed-agents-secure、hillclimb、preserved-thinking-migration 等。
  • /claude-in-chrome通过 Claude in Chrome 扩展让 Claude 在你的浏览器里执行任务，如测试页面、填写表单、读取控制台日志。需启用 Chrome 集成（如 claude --chrome）。
  • /ide管理与 VS Code、JetBrains 等编辑器的集成并显示状态。
  • /install-github-app为仓库安装 Claude GitHub App，可选设置 GitHub Actions 工作流和密钥。仅适用于 github.com 仓库。
  • /install-slack-app安装 Claude Slack 应用，会打开浏览器完成 OAuth 授权。
  • /plugin管理插件（一包命令、技能、代理、工具）。不带参数打开菜单，或用 list、install、enable、disable 直接操作。安装后若提示，需要 /reload-plugins。
  • /plugin-authoring加载编写「mod」（修改 Claude 界面或行为的小扩展）的参考资料。来自内置插件，可在 /plugin 中关闭。
