/insights

英文 insights ＝ 洞察、分析

生成一份 HTML 报告，分析你在本机的近期使用：常用项目、使用方式、容易出错的地方、值得尝试的功能。云端会话中不可用。

最佳用法

用了一段时间后 /insights，发现自己从没用过的好功能。

适用场景

  • 系统学习怎么用/powerup → /help → /insights

相关命令 · 项目与文件

  • /init生成项目说明书 CLAUDE.md
  • /add-dir本次会话额外允许访问另一个文件夹，当前工作位置不变。输入部分路径会提示补全，按 Tab 接受。被添加文件夹里的大部分 .claude/ 配置不会被读取；多数网络路径不能添加。
  • /cd把当前会话移到另一个工作文件夹，对话保留。和 /add-dir 的区别：/cd 是搬家，/add-dir 是多开一扇门。
  • /diff查看工作区的改动，包括 Claude 目前做的修改。
  • /import把本机 OpenAI Codex、Google Gemini CLI 或 Cursor 的配置（说明文件、MCP 服务器、命令、子代理、技能）导入 Claude Code。--dry-run 只预览不写入。部分云平台不可用；从 Cursor 导入需 v2.1.265+。
  • /team-onboarding分析你过去 30 天的会话、命令和 MCP 使用情况，生成一份 Markdown 入门指南，新同事可以直接作为第一条消息粘贴。
