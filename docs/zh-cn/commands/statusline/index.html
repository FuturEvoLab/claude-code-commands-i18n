/statusline

英文 status line ＝ 状态栏

配置底部状态栏。用文字描述想显示的内容，或不带参数从你的 shell 提示符自动配置。

最佳用法

/statusline 显示当前模型和 git 分支。

相关命令 · 设置与界面

  • /color设置当前会话输入栏的颜色：red、blue、green、yellow、purple、orange、pink、cyan；default 恢复；不带参数随机。
  • /config打开设置界面（主题、模型、输出风格等）。也可直接写 key=value 修改，例如 /config theme=dark。/config --help 列出可用的键。
  • /focus切换专注视图：只显示你的最后一条提问、一行工具调用摘要和最终回答。仅全屏渲染模式可用。
  • /keybindings打开快捷键配置文件。
  • /scroll-speed交互式调整鼠标滚轮速度。仅全屏渲染模式可用，JetBrains 终端中不可用。
  • /terminal-setup在 VS Code、Cursor、Devin Desktop、Alacritty、Zed 中安装 Shift+Enter 换行；Apple 终端改为 Option+Enter 并关闭提示音；iTerm2 中开启剪贴板权限让 /copy 可用。
  • /theme更换配色主题：auto 跟随终端、浅色/深色、色觉友好主题、ANSI 主题和自定义主题。
  • /tui设置终端界面渲染方式并保留对话重新启动。fullscreen 为不闪烁的全屏模式；不带参数显示当前方式。
