/memory

英文 memory ＝ 记忆

编辑 CLAUDE.md 记忆文件，开关「自动记忆」，查看自动记住的条目。

最佳用法

想让 Claude 每次都用中文回答：/memory 打开 CLAUDE.md，写入「请始终用简体中文回答」。

适用场景

  • 让 Claude 一直用中文回答/init → /memory

相关命令 · 对话与上下文

  • /clear开始全新对话，旧对话可找回
  • /compact压缩长对话，腾出空间继续聊
  • /context查看记忆空间被什么占满
  • /plan先出方案、你批准后再动手
  • /resume回到以前的对话
  • /rewind撤销：把代码和对话退回之前
  • /autocompact设置上下文用到多满时自动压缩，例如 500k；auto 恢复为模型默认值。保存到用户设置并立即生效。
  • /branch在当前位置为对话建一个分支并切换过去，用来尝试另一个方向；原对话保留，可用 /resume 回去。（这是对话分支，不是 Git 分支。）
