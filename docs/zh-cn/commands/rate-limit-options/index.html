/rate-limit-options

英文 rate limit options ＝ 用量上限的应对选项

claude.ai 用量上限阻止请求时显示选项：等待重置后自动继续、添加用量额度或升级套餐。需要 claude.ai 订阅。

最佳用法

深夜跑任务被限额卡住：选择「重置后自动继续」，第二天醒来已完成。

相关命令 · 账号与用量

  • /usage查看费用和用量上限
  • /login登录 Anthropic 账号。
  • /logout退出 Anthropic 账号。
  • /passes把一周免费 Claude Code 分享给朋友。仅在账号符合条件时显示。
  • /status打开设置的「状态」页：版本、模型、账号、连接情况。Claude 回复中也能运行。
  • /upgrade在浏览器打开升级套餐的页面。
  • /usage-credits达到上限时配置或申请用量额度：打开账单设置页；Team/Enterprise 无账单权限的成员则向管理员发送申请。旧名 /extra-usage。
