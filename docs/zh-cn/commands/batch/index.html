/batch<instruction>

英文 batch ＝ 批量

技能⇄ 会大范围修改文件

大规模并行改代码：先研究代码库，把工作拆成 5～30 个独立单元并给出计划；你批准后，每个单元由一个后台子代理在独立 worktree 中实现、测试并提交。需要 Git 仓库（或相应 hook）。

最佳用法

/batch 把 src/ 从 JavaScript 迁移到 TypeScript。

安全标记

⇄ 会大范围修改文件: 可能一次修改或还原很多文件。运行前先用 Git 提交或备份，运行后用 /diff 检查。

适用场景

  • 同时做几件事 / 放后台跑/fork → /subtask → /background → /tasks → /batch

相关命令 · 并行与后台

  • /agents新版本中只显示一条提示：直接让 Claude 创建或管理子代理，或编辑 .claude/agents/ 文件夹。v2.1.197 及更早版本会打开管理界面。
  • /background把当前会话转为后台代理继续运行，释放终端。可附带最后一条指令。用 claude agents 查看。
  • /fork把当前对话复制成一个新的后台会话，这边继续工作。带上指令则副本立即开始。副本一般会先创建自己的 worktree 再改代码。
  • /list-agents列出 Claude 可以发消息的子代理、团队成员和其他会话，以及各自的名字。仅在启用跨会话消息时可用。
  • /stop停止你当前连接的后台会话，记录和 worktree 保留。只想断开不停止，用 /exit 或按 ←。
  • /subtask派出一个继承完整对话的后台子代理去做任务，完成后结果回到当前对话。与 /fork 的区别：/subtask 的结果会汇报回来，/fork 是独立的会话。
  • /tasks查看和管理当前会话的后台工作，包括已完成的子代理。
  • /workflow-authoring加载编写动态工作流脚本的参考资料。Claude 一般会自动加载；手动修改已保存脚本前可以自己运行。仅在启用动态工作流时可用。
