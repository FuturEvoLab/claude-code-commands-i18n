/model[model]

切换模型

英文 model ＝ 模型

★ 新手推荐

切换 AI 模型，并保存为新会话的默认模型。不带参数打开选择器；支持的模型可用左右方向键调思考力度；在某一行按 s 只对当前会话生效。

最佳用法

简单改文案用较快较省的模型；遇到难 bug 时 /model opus 换更强的模型。

适用场景

  • 大改动前，想先看方案再让它动手/plan → /effort → /model
  • 省钱、省额度/usage → /model → /effort → /context

相关命令 · 模型与推理

  • /advisor开关「顾问工具」：任务关键时刻请第二个模型提供建议。可填 fable、opus、sonnet 或完整模型 ID（fable 需要相应权限）。不带参数打开选择器。
  • /effort设置思考力度：low 到 xhigh、max 或 auto；status 显示当前值。max 只对当前会话有效。ultracode on|off 开关 ultracode 模式。
  • /fast开关快速模式（同一个模型，输出更快）。在 Claude 回复中途也能切换，但正在进行的这一轮仍按原速度完成。计费方式请以官方 fast mode 说明为准。
  • /output-style列出或切换输出风格（回答的写法），例如 /output-style concise。
