/resume[session]

回到以前的对话

英文 resume ＝ 继续、恢复

★ 新手推荐

按 ID 或名字恢复以前的对话，不写参数则打开对话列表。后台会话会标记为 bg。

最佳用法

昨天没做完就关了电脑：今天 /resume，选昨天的对话接着做。

同义命令

/continue

适用场景

  • 换一件不相关的事，从头开始/clear → /resume
  • 接着做昨天没做完的/resume → /rename → /recap

相关命令 · 对话与上下文

  • /clear开始全新对话，旧对话可找回
  • /compact压缩长对话，腾出空间继续聊
  • /context查看记忆空间被什么占满
  • /plan先出方案、你批准后再动手
  • /rewind撤销：把代码和对话退回之前
  • /autocompact设置上下文用到多满时自动压缩，例如 500k；auto 恢复为模型默认值。保存到用户设置并立即生效。
  • /branch在当前位置为对话建一个分支并切换过去，用来尝试另一个方向；原对话保留，可用 /resume 回去。（这是对话分支，不是 Git 分支。）
  • /btw就当前会话问一个旁支问题，答案不会加入对话历史。不带问题则显示最近一次旁支问答。
