/context[all]

查看记忆空间被什么占满

英文 context ＝ 上下文（Claude 当前能「记住」的内容）

★ 新手推荐

用彩色方格图显示上下文用了多少、被什么占用，并给出节省建议和容量警告。all 展开全部明细。

最佳用法

感觉 Claude 变「健忘」或用量涨得快时，先 /context 看是不是被大文件或工具输出占满。

适用场景

  • 对话太长，Claude 变慢或开始忘事/context → /compact → /autocompact
  • 省钱、省额度/usage → /model → /effort → /context

相关命令 · 对话与上下文

  • /clear开始全新对话，旧对话可找回
  • /compact压缩长对话，腾出空间继续聊
  • /plan先出方案、你批准后再动手
  • /resume回到以前的对话
  • /rewind撤销：把代码和对话退回之前
  • /autocompact设置上下文用到多满时自动压缩，例如 500k；auto 恢复为模型默认值。保存到用户设置并立即生效。
  • /branch在当前位置为对话建一个分支并切换过去，用来尝试另一个方向；原对话保留，可用 /resume 回去。（这是对话分支，不是 Git 分支。）
  • /btw就当前会话问一个旁支问题，答案不会加入对话历史。不带问题则显示最近一次旁支问答。
