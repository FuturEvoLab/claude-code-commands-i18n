/advisor[model|off]

英文 advisor ＝ 顾问

开关「顾问工具」：任务关键时刻请第二个模型提供建议。可填 fable、opus、sonnet 或完整模型 ID（fable 需要相应权限）。不带参数打开选择器。

最佳用法

平时用较快的模型干活，又怕关键决策出错：/advisor opus。

相关命令 · 模型与推理

  • /model切换模型
  • /effort设置思考力度：low 到 xhigh、max 或 auto；status 显示当前值。max 只对当前会话有效。ultracode on|off 开关 ultracode 模式。
  • /fast开关快速模式（同一个模型，输出更快）。在 Claude 回复中途也能切换，但正在进行的这一轮仍按原速度完成。计费方式请以官方 fast mode 说明为准。
  • /output-style列出或切换输出风格（回答的写法），例如 /output-style concise。
