/setup-vertex

英文 set up Vertex ＝ 配置 Google Cloud

通过向导配置 Google Cloud Agent Platform 的认证、项目、区域和模型。设置 CLAUDE_CODE_USE_VERTEX=1 之前不会出现在菜单中，需要完整输入。

最佳用法

公司通过 Google Cloud 使用 Claude 时。

  • /mobile显示下载 Claude 手机 App 的二维码。
