/schedule[description]

英文 schedule ＝ 日程、定时

创建、修改、列出或运行云端定时任务（以前叫 routines），通过对话引导设置，也可以问最近的运行记录。使用 Console API 密钥时不可用。

最佳用法

/schedule 每个工作日早上 9 点检查仓库新 issue 并总结。

同义命令

/routines

适用场景

  • 让它反复做或定时做/loop → /schedule → /goal

相关命令 · 定时与自动化

  • /loop按间隔重复执行一条指令
  • /autofix-pr开一个云端会话盯住当前分支的 PR，CI 失败或有人留评审意见时自动推送修复。需要 gh 命令行工具和云端会话权限。
  • /deep-research多代理工作流：大量搜索网页、抓取并交叉核对来源，写成带引用的报告。在后台运行。
