/dataviz[request]

英文 data visualization ＝ 数据可视化

技能

图表设计指南：为数据选择合适的图表形式、按用途配色，用自带脚本检查色盲友好和对比度。

最佳用法

/dataviz 把这份月度销售表做成趋势图。

适用场景

  • 做幻灯片、设计稿或图表/slides → /design → /dataviz → /artifacts

相关命令 · 网页、幻灯片与设计

  • /artifact-capabilities加载 artifact 运行时可用能力的参考，例如调用你的连接器、给访客提供文件下载，以及你的账号有哪些。Claude 一般会自动加载。
  • /artifact-diagramming加载在 artifact 中画示意图的规范：何时需要图、画什么、如何写出在浅色和深色主题下都清楚的 SVG。
  • /artifacts列出你拥有或别人分享给你的 artifact（网页成品），可以接入当前会话、在浏览器打开或复制链接。仅在支持 artifact 的环境可用。
  • /design在一张画布上绘制界面草图、页面流程、落地页或海报（Claude Design artifact），可在桌面浏览器编辑并导出 PNG 或 PDF。Bedrock、Vertex 等第三方平台不可用。
  • /design consent授予或撤销 Claude 对 Claude Design 的访问权限。当 Claude 的回复要求你运行 /design consent 时，需要你自己在输入框中输入。
  • /design-login为 /design-sync 用 claude.ai 账号授权。当 /design-sync 或 /design consent 提示时使用。
  • /design-sync把仓库中的 React 设计系统转换并上传到 Claude Design，让生成的设计使用你真实的组件。首次同步会逐个验证组件，大仓库可能要几个小时。上传目标是独立的 claude.ai/design 网站，该网站将于 2026 年 12 月 14 日前关闭。
  • /slides根据你的描述生成一套 Claude Slides 演示文稿（artifact）。需要支持 artifact 的会话和可用的 Slides 模板。
