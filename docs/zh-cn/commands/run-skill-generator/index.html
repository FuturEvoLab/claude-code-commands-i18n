/run-skill-generator

英文 skill generator ＝ 技能生成器

技能

为本项目写一个专属技能，教会 /run 和 /verify 如何从干净环境构建、启动和操作你的应用。

最佳用法

项目启动步骤复杂（要先起数据库等），跑一次，以后 /run 一步到位。

相关命令 · 审查与验证

  • /code-review提交前检查 bug，可自动修复
  • /run启动并操作你的项目应用，看改动的实际效果。
  • /security-review对比当前分支与远程默认分支的差异，找出安全隐患，如注入、认证问题、数据泄露。需要名为 origin 的远程仓库。
  • /simplify4 个审查代理并行检查改动：能否复用现有代码、能否更简单、效率、抽象层级是否合适，并直接改好。不查正确性 bug（那是 /code-review 的事）。
  • /ultrareview在云端沙箱里用多个代理深度审查代码。推荐写法是 /code-review ultra，/ultrareview 是别名。Pro、Max、Ultra 含 3 次免费，之后需要用量额度。
  • /verify真正构建并运行你的应用、观察结果，确认改动有效，而不是只看测试或类型检查。只在你手动调用时运行。
