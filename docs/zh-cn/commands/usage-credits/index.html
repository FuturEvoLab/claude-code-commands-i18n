/usage-credits

英文 usage credits ＝ 用量额度

¥ 可能产生费用

达到上限时配置或申请用量额度：打开账单设置页；Team/Enterprise 无账单权限的成员则向管理员发送申请。旧名 /extra-usage。

最佳用法

团队账号用完额度，向管理员申请。

安全标记

¥ 可能产生费用: 可能消耗付费额度或产生额外费用。使用前用 /usage 确认额度，并查看官方价格说明。

相关命令 · 账号与用量

  • /usage查看费用和用量上限
  • /login登录 Anthropic 账号。
  • /logout退出 Anthropic 账号。
  • /passes把一周免费 Claude Code 分享给朋友。仅在账号符合条件时显示。
  • /rate-limit-optionsclaude.ai 用量上限阻止请求时显示选项：等待重置后自动继续、添加用量额度或升级套餐。需要 claude.ai 订阅。
  • /status打开设置的「状态」页：版本、模型、账号、连接情况。Claude 回复中也能运行。
  • /upgrade在浏览器打开升级套餐的页面。
