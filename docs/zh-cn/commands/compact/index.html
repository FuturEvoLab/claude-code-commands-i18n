/compact[instructions]

压缩长对话，腾出空间继续聊

英文 compact ＝ 压缩

★ 新手推荐

把到目前为止的对话总结成摘要，腾出上下文空间，对话继续。可以附上「摘要要重点保留什么」。

最佳用法

长时间对话后：/compact 保留数据库结构和尚未修复的 bug 列表。

适用场景

  • 对话太长，Claude 变慢或开始忘事/context → /compact → /autocompact

相关命令 · 对话与上下文

  • /clear开始全新对话，旧对话可找回
  • /context查看记忆空间被什么占满
  • /plan先出方案、你批准后再动手
  • /resume回到以前的对话
  • /rewind撤销：把代码和对话退回之前
  • /autocompact设置上下文用到多满时自动压缩，例如 500k；auto 恢复为模型默认值。保存到用户设置并立即生效。
  • /branch在当前位置为对话建一个分支并切换过去，用来尝试另一个方向；原对话保留，可用 /resume 回去。（这是对话分支，不是 Git 分支。）
  • /btw就当前会话问一个旁支问题，答案不会加入对话历史。不带问题则显示最近一次旁支问答。
