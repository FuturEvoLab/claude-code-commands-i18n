/rewind

撤销：把代码和对话退回之前

英文 rewind ＝ 倒带

★ 新手推荐⇄ 会大范围修改文件

把对话和/或代码退回到之前的某个检查点，或者从选中的消息开始做摘要。类似游戏「读档」。

最佳用法

Claude 把文件改坏了：/rewind，选择改动之前的那条消息，代码和对话一起恢复。

同义命令

/checkpoint · /undo

安全标记

⇄ 会大范围修改文件: 可能一次修改或还原很多文件。运行前先用 Git 提交或备份，运行后用 /diff 检查。

适用场景

  • Claude 改坏了，我想撤销/rewind → /diff

相关命令 · 对话与上下文

  • /clear开始全新对话，旧对话可找回
  • /compact压缩长对话，腾出空间继续聊
  • /context查看记忆空间被什么占满
  • /plan先出方案、你批准后再动手
  • /resume回到以前的对话
  • /autocompact设置上下文用到多满时自动压缩，例如 500k；auto 恢复为模型默认值。保存到用户设置并立即生效。
  • /branch在当前位置为对话建一个分支并切换过去，用来尝试另一个方向；原对话保留，可用 /resume 回去。（这是对话分支，不是 Git 分支。）
  • /btw就当前会话问一个旁支问题，答案不会加入对话历史。不带问题则显示最近一次旁支问答。
