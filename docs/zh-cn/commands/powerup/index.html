/powerup

互动课程，系统学习功能

英文 power up ＝ 能力提升

★ 新手推荐

通过带动画演示的互动小课程学习 Claude Code 的功能。

最佳用法

新手系统学习的最佳入口。

适用场景

  • 系统学习怎么用/powerup → /help → /insights

相关命令 · 诊断与反馈

  • /doctor出问题时先体检
  • /help查看帮助和全部命令
  • /bug报告 bug 或分享对话。你可以选择附带多少会话记录，并在同意页面确认后才会发送。
  • /debug为当前会话开启调试日志，并通过阅读日志排查问题。从运行时刻开始记录；可附上问题描述。
  • /exit退出命令行。在已连接的后台会话中，它只是断开，会话继续运行。
  • /feedback发送产品反馈，使用与 /bug 相同的对话框和同意步骤。
  • /heapdump把 JavaScript 内存快照和内存明细写到桌面，用于排查内存占用过高。报告问题时只附 -diagnostics.json；.heapsnapshot 含完整对话和凭据，不要分享。菜单中隐藏，需完整输入。
  • /release-notes在版本选择器中查看更新日志。内容显示在记录里，但不会进入 Claude 的上下文。
