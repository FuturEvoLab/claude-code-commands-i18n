/design consent

英語 consent / revoke ＝ 同意 / 取り消し

Claude Design へのアクセスを許可・取り消します。Claude の返答で /design consent を求められたら、自分で入力してください。

おすすめの使い方

許可を求められたら自分で /design consent と入力。

別名

/design revoke

関連するコマンド · ページ・スライド・デザイン

  • /artifact-capabilitiesアーティファクトで使える実行時機能（コネクターの呼び出し、ファイルのダウンロード提供など）と、自分のアカウントで使えるものの資料を読み込みます。通常は Claude が自動で読み込みます。
  • /artifact-diagrammingアーティファクトで図を描くためのガイドを読み込みます。図が必要な場面、何を描くか、明暗どちらのテーマでも見やすい SVG の書き方。
  • /artifacts自分が持っている、または共有されたアーティファクト（Web ページ）を一覧表示し、セッションへの追加・ブラウザーで開く・リンクのコピーができます。対応環境のみ。
  • /datavizグラフ作成のガイドです。データに合う形を選び、役割ごとに色を割り当て、付属スクリプトで色覚多様性への配慮とコントラストを確認します。
  • /designUI のラフ、画面遷移、LP、ポスターを 1 枚のキャンバスに描きます（Claude Design のアーティファクト）。デスクトップのブラウザーで編集し、PNG・PDF で書き出せます。Bedrock や Vertex などでは使えません。
  • /design-login/design-sync 用に claude.ai アカウントで認可します。/design-sync や /design consent に求められたときに使います。
  • /design-syncリポジトリの React デザインシステムを変換して Claude Design にアップロードし、実際のコンポーネントでデザインできるようにします。初回は全コンポーネントを検証するため、大きなリポジトリでは数時間かかることも。アップロード先の claude.ai/design は 2026 年 12 月 14 日までに終了予定です。
  • /slides説明をもとに Claude Slides のプレゼン（アーティファクト）を作ります。アーティファクト対応のセッションと Slides テンプレートが必要です。
