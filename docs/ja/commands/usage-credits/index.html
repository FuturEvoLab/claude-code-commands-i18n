/usage-credits

英語 usage credits ＝ 使用量クレジット

¥ 費用が発生する場合あり

上限に達したときにクレジットを設定・申請します。請求設定ページを開くか、Team／Enterprise で請求権限がない場合は管理者に申請を送ります。旧名 /extra-usage。

おすすめの使い方

チームの上限に達したら管理者に申請。

安全マーク

¥ 費用が発生する場合あり: 有料の使用量を消費したり、追加料金が発生したりする場合があります。使う前に /usage で確認し、公式の料金説明を確認してください。

関連するコマンド · アカウントと使用量

  • /usage料金と使用量の上限を確認する
  • /loginAnthropic アカウントにログインします。
  • /logoutAnthropic アカウントからログアウトします。
  • /passesClaude Code の 1 週間無料体験を友人に共有します。対象アカウントのみ表示。
  • /rate-limit-optionsclaude.ai の使用量上限で止まったときの選択肢を表示します：リセット後に自動で続ける、クレジットを追加、プランを上げる。claude.ai のサブスクリプションが必要。
  • /status設定の「ステータス」タブを開き、バージョン・モデル・アカウント・接続状況を表示します。応答中でも使えます。
  • /upgrade上位プランへのアップグレードページをブラウザーで開きます。
