/permissions

どの操作を確認なしで許可するか決める

英語 permissions ＝ 権限

★ 初心者向け⚑ 安全設定を変更

ツール権限の「許可・確認・拒否」ルールを管理します。範囲ごとの確認、ルールの追加・削除、作業ディレクトリの管理、「Recently blocked」タブ（自動モードが止めた操作）と分類ルールの確認ができます。

おすすめの使い方

毎回「npm test を実行してよいか」と聞かれるのが面倒なら、ここで許可に。

別名

/allowed-tools

安全マーク

⚑ 安全設定を変更: Claude が確認なしで実行できる範囲など、安全に関わる設定を変えます。理解して信頼できる操作だけを許可してください。

こんな場面で使う

  • 許可の確認ダイアログが多すぎる/permissions → /fewer-permission-prompts

関連するコマンド · 権限とセキュリティ

  • /auto-mode-setupプロジェクトと最近のセッションから autoMode.environment の項目を下書きし、確認後ユーザー設定に保存します。自動モードの判断精度が上がります。バージョンとプランの条件あり。
  • /fewer-permission-prompts履歴からよく使う読み取り専用の Bash・MCP 呼び出しを探し、優先度順にプロジェクトの .claude/settings.json の許可リストへ追加します。
  • /hooksフックの設定を確認します。
  • /privacy-settingsプライバシー設定を確認・変更します。Pro・Max・Ultra のみ。
  • /sandboxサンドボックスモードを切り替えます。対応プラットフォームのみ。
  • /update-config設定の変更（コマンドの許可、環境変数、フックの追加）を言葉で伝えると、Claude が該当の settings.json を編集します。テーマやモデルは /config。
