/plugin[subcommand]

英語 plugin ＝ プラグイン

プラグイン（コマンド・スキル・エージェント・ツールのセット）を管理します。引数なしでメニュー、list・install・enable・disable で直接操作。案内が出たら /reload-plugins。

おすすめの使い方

/plugin でマーケットプレイスを見て、仕事に合うものを入れます。

こんな場面で使う

  • 外部ツールの接続や機能の追加をしたい/mcp → /plugin → /skills

関連するコマンド · プラグイン・スキル・外部連携

  • /mcp外部ツールとの接続を管理する
  • /chromeClaude in Chrome の設定を行います。
  • /claude-apiプロジェクトの言語に合った Claude API と Managed Agents の資料を読み込みます。コードが anthropic を import していると自動で有効。サブコマンドは migrate・upgrade・api-version・cost-optimize・latency-optimize・build-eval・prompt-audit・managed-agents-onboard・managed-agents-secure・hillclimb・preserved-thinking-migration など。
  • /claude-in-chromeClaude in Chrome 拡張を通して、ページのテスト・フォーム入力・コンソールログの確認などをブラウザーで行います。Chrome 連携の有効化（例：claude --chrome）が必要です。
  • /ideVS Code や JetBrains などのエディターとの連携を管理し、状態を表示します。
  • /install-github-appリポジトリに Claude GitHub App を入れ、必要なら GitHub Actions のワークフローとシークレットも設定します。github.com のリポジトリのみ。
  • /install-slack-appClaude の Slack アプリを入れます。ブラウザーが開き OAuth 認可を行います。
  • /plugin-authoring「mod」（Claude の画面や動作を変える小さな拡張）を書くための資料を読み込みます。組み込みプラグインのスキルで、/plugin でオフにできます。
