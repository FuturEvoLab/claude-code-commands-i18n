/schedule[description]

英語 schedule ＝ スケジュール

クラウドの定期実行タスク（旧 routines）を作成・変更・一覧・実行します。会話形式で設定でき、最近の実行結果も聞けます。Console の API キーでは使えません。

おすすめの使い方

/schedule 平日の毎朝 9 時に新しい issue をまとめて。

別名

/routines

こんな場面で使う

  • 繰り返し・決まった時刻に実行したい/loop → /schedule → /goal

関連するコマンド · 自動化とスケジュール

  • /loop一定間隔で指示を繰り返す
  • /autofix-pr現在のブランチの PR をクラウドセッションが見張り、CI の失敗やレビューコメントがあれば修正を push します。gh CLI とクラウドセッションの利用権が必要です。
  • /deep-researchマルチエージェントのワークフローです。Web を広く検索し、情報源を取得・照合して、出典付きのレポートにまとめます。バックグラウンドで動きます。
