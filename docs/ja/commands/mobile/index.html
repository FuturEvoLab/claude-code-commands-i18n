/mobile

英語 mobile ＝ スマートフォン

Claude モバイルアプリのダウンロード用 QR コードを表示します。

おすすめの使い方

スマホで進み具合を見たり操作したりしたいとき。

別名

/ios · /android

こんな場面で使う

  • パソコンを離れてスマホで続けたい/remote-control → /mobile → /desktop

関連するコマンド · クラウド・リモート・他のデバイス

  • /desktop今のセッションを Claude Code のデスクトップアプリで続けます。macOS か x64 Windows と Claude のサブスクリプションが必要。
  • /remote-controlこのセッションを claude.ai（Web やスマホ）から操作できるようにします。claude.ai のサブスクリプションが必要。
  • /remote-envCLI からクラウドセッションを始めるときの既定の環境を選びます。
  • /setup-bedrockウィザードで Amazon Bedrock の認証・リージョン・モデルを設定します。CLAUDE_CODE_USE_BEDROCK=1 を設定するまでメニューに出ないので、全部入力します。
  • /setup-vertexウィザードで Google Cloud Agent Platform の認証・プロジェクト・リージョン・モデルを設定します。CLAUDE_CODE_USE_VERTEX=1 を設定するまでメニューに出ないので、全部入力します。
  • /teleportクラウドのセッションをこのターミナルに取り込みます（ブランチと会話を取得）。claude.ai のサブスクリプションが必要。
  • /web-setupローカルの gh CLI の認証情報を使って、クラウドセッション用に GitHub アカウントを接続します。
