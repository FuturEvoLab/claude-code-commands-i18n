/list-agents

英語 list agents ＝ エージェント一覧

v2.1.224 以降

Claude がメッセージを送れるサブエージェント・チームメイト・他のセッションと、その名前を一覧表示します。セッション間メッセージが有効な場合のみ。

おすすめの使い方

複数のセッションで連携するとき、お互いの名前を確認。

別名

/peers

関連するコマンド · 並列・バックグラウンド

  • /agents新しいバージョンでは案内が表示されるだけです：Claude にサブエージェントの作成・管理を頼むか、.claude/agents/ を直接編集します。v2.1.197 以前は管理画面が開きます。
  • /background今のセッションをバックグラウンドのエージェントとして動かし続け、ターミナルを空けます。最後の指示を添えることもできます。確認は claude agents。
  • /batch大規模な変更を並列で行います。コードを調べて 5〜30 の独立した単位に分けて計画を示し、承認後は単位ごとにバックグラウンドのサブエージェントが独立した worktree で実装・テスト・反映します。Git リポジトリ（または対応する hook）が必要です。
  • /fork今の会話を新しいバックグラウンドセッションに複製し、こちらは作業を続けます。指示を付けると複製がすぐ作業開始。複製は通常、自分用の worktree を作ってから編集します。
  • /stop接続中のバックグラウンドセッションを停止します（記録と worktree は残ります）。止めずに離れたいだけなら /exit か ←。
  • /subtask会話全体を引き継いだバックグラウンドのサブエージェントに作業を任せ、終わると結果がこの会話に戻ります。/fork との違い：/subtask は結果が戻り、/fork は独立したセッションです。
  • /tasksこのセッションのバックグラウンド作業（完了したサブエージェントを含む）を確認・管理します。
  • /workflow-authoring動的ワークフローのスクリプトを書くための資料を読み込みます。通常は Claude が自動で読み込みます。保存済みスクリプトを手で直す前に実行するとよいでしょう。動的ワークフローが有効な場合のみ。
