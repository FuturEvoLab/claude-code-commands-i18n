/deep-research<question>

英語 deep research ＝ 詳細リサーチ

ワークフロー

マルチエージェントのワークフローです。Web を広く検索し、情報源を取得・照合して、出典付きのレポートにまとめます。バックグラウンドで動きます。

おすすめの使い方

/deep-research 主要な AI 動画生成ツールの料金と画質の比較。

関連するコマンド · 自動化とスケジュール

  • /loop一定間隔で指示を繰り返す
  • /autofix-pr現在のブランチの PR をクラウドセッションが見張り、CI の失敗やレビューコメントがあれば修正を push します。gh CLI とクラウドセッションの利用権が必要です。
  • /scheduleクラウドの定期実行タスク（旧 routines）を作成・変更・一覧・実行します。会話形式で設定でき、最近の実行結果も聞けます。Console の API キーでは使えません。
