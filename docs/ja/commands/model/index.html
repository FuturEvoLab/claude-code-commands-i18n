/model[model]

モデルを切り替える

英語 model ＝ モデル

★ 初心者向け

AI モデルを切り替え、新しいセッションの既定にも保存します。引数なしで選択画面。対応モデルでは左右キーで推論の深さを調整、行で s を押すとこのセッションだけ切り替えます。

おすすめの使い方

簡単な修正は速くて安いモデル、難しいバグは /model opus で強いモデルに。

こんな場面で使う

  • 大きな変更の前に、まず計画を見たい/plan → /effort → /model
  • 料金や使用量を節約したい/usage → /model → /effort → /context

関連するコマンド · モデルと推論

  • /advisor「アドバイザー」を切り替えます。作業の重要な場面で別のモデルに助言を求めます。fable・opus・sonnet または完全なモデル ID を指定（fable は利用権限が必要）。引数なしで選択画面。
  • /effort推論の深さを low〜xhigh、max、auto から設定します。status で現在値を表示。max はこのセッションのみ。ultracode on|off で ultracode を切り替えます。
  • /fast高速モード（同じモデルで出力が速くなる）を切り替えます。応答中でも切り替えられますが、進行中のターンは元の速度のまま終わります。料金は公式の fast mode の説明を確認してください。
  • /output-style出力スタイル（回答の書き方）を一覧表示・切り替えします。例：/output-style concise。
