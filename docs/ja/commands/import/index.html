/import[codex|gemini|cursor] [--dry-run] [--yes]

英語 import ＝ インポート・取り込み

⇄ ファイルを広く変更

OpenAI Codex・Google Gemini CLI・Cursor の設定（指示ファイル、MCP サーバー、コマンド、サブエージェント、スキル）を取り込みます。--dry-run はプレビューのみ。一部のクラウド環境では使えません。Cursor からの取り込みには v2.1.265 以降が必要です。

おすすめの使い方

Cursor から移るとき：まず /import cursor --dry-run で内容を確認してから本番の取り込み。

安全マーク

⇄ ファイルを広く変更: 多くのファイルを一度に変更・復元する場合があります。実行前に Git でコミットかバックアップをし、実行後は /diff で確認してください。

関連するコマンド · プロジェクトとファイル

  • /initプロジェクトの説明書 CLAUDE.md を作る
  • /add-dirこのセッションで別のフォルダーへのアクセスを追加します（作業場所はそのまま）。パスの途中まで入力すると候補が出て Tab で確定。追加したフォルダーの .claude/ 設定はほとんど読み込まれず、ネットワークパスの多くは追加できません。
  • /cd会話を残したまま、セッションを別のフォルダーに移します。/add-dir との違い：/cd は引っ越し、/add-dir は入り口を一つ増やすイメージです。
  • /diff作業ツリーの変更（Claude がこれまでに行った編集を含む）を確認します。
  • /insightsこのマシンでの最近の使い方（よく使うプロジェクト、使い方、つまずきやすい点、試すとよい機能）を分析した HTML レポートを作ります。クラウドセッションでは使えません。
  • /team-onboarding過去 30 日のセッション・コマンド・MCP の使い方を分析し、新しいメンバーが最初のメッセージとして貼り付けられる Markdown のガイドを作ります。
