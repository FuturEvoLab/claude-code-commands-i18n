/autofix-pr[prompt]

英語 auto-fix PR ＝ PR の自動修正

↗ 外部に送信

現在のブランチの PR をクラウドセッションが見張り、CI の失敗やレビューコメントがあれば修正を push します。gh CLI とクラウドセッションの利用権が必要です。

おすすめの使い方

lint だけ任せたいなら：/autofix-pr lint と型エラーだけ直して。

安全マーク

↗ 外部に送信: 会話・コード・コメントを他のサービス（Anthropic、GitHub、クラウドセッション、ブラウザー上のサイトなど）に送ったり、リモートに push したりします。内容と送信先を確認してから実行してください。

関連するコマンド · 自動化とスケジュール

  • /loop一定間隔で指示を繰り返す
  • /deep-researchマルチエージェントのワークフローです。Web を広く検索し、情報源を取得・照合して、出典付きのレポートにまとめます。バックグラウンドで動きます。
  • /scheduleクラウドの定期実行タスク（旧 routines）を作成・変更・一覧・実行します。会話形式で設定でき、最近の実行結果も聞けます。Console の API キーでは使えません。
