/heapdump

英語 heap dump ＝ ヒープダンプ（メモリーの記録）

⚿ 機密情報を含む場合あり

JavaScript のヒープスナップショットとメモリー内訳をデスクトップに書き出し、メモリー使用量が多い問題を調べます。報告時は -diagnostics.json だけ添付。.heapsnapshot には会話全体と認証情報が含まれるので共有しないこと。メニューには出ないので全部入力。

おすすめの使い方

数 GB のメモリーを使っているとき、報告用に。

安全マーク

⚿ 機密情報を含む場合あり: 作られるファイル・クリップボード・レポートに、会話内容・API キー・パスワード・個人情報が含まれる場合があります。共有する前に必ず確認し、該当する部分を削除・伏せ字にしてください。
