/rewind

元に戻す：コードと会話を以前の状態へ

英語 rewind ＝ 巻き戻し

★ 初心者向け⇄ ファイルを広く変更

会話とコード（片方だけも可）を以前のチェックポイントに戻します。選んだメッセージ以降を要約することもできます。ゲームの「セーブデータを読み込む」に近い機能です。

おすすめの使い方

Claude がファイルを壊してしまったら：/rewind で変更前のメッセージを選ぶと、コードと会話がまとめて元に戻ります。

別名

/checkpoint · /undo

安全マーク

⇄ ファイルを広く変更: 多くのファイルを一度に変更・復元する場合があります。実行前に Git でコミットかバックアップをし、実行後は /diff で確認してください。

こんな場面で使う

  • Claude が壊したので元に戻したい/rewind → /diff

関連するコマンド · 会話とコンテキスト

  • /clear会話をリセットして新しく始める（前の会話は戻せる）
  • /compact長い会話を要約して空きを作り、続ける
  • /contextコンテキストを何が埋めているか見る
  • /plan先に計画を出し、承認後に作業する
  • /resume以前の会話に戻る
  • /autocompactコンテキストがどれだけ埋まったら自動圧縮するかを設定します（例：500k）。auto でモデルの既定値に戻ります。ユーザー設定に保存され、すぐ反映されます。
  • /branch今の時点で会話の分岐を作って切り替え、別の方向を試せます。元の会話は残り /resume で戻れます。（Git のブランチではなく会話の分岐です。）
  • /btw今の会話について、履歴に残さない「ついでの質問」をします。質問なしで実行すると直近の質問と回答を表示します。
