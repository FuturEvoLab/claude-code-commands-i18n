/export[filename]

英語 export ＝ エクスポート・書き出し

⚿ 機密情報を含む場合あり

今の会話をプレーンテキストで書き出します。ファイル名を指定すると直接保存、なしならコピーか保存かを選べます。

おすすめの使い方

役に立ったトラブル対応の記録を /export 対応記録.txt で保存して共有。

安全マーク

⚿ 機密情報を含む場合あり: 作られるファイル・クリップボード・レポートに、会話内容・API キー・パスワード・個人情報が含まれる場合があります。共有する前に必ず確認し、該当する部分を削除・伏せ字にしてください。

関連するコマンド · 会話とコンテキスト

  • /clear会話をリセットして新しく始める（前の会話は戻せる）
  • /compact長い会話を要約して空きを作り、続ける
  • /contextコンテキストを何が埋めているか見る
  • /plan先に計画を出し、承認後に作業する
  • /resume以前の会話に戻る
  • /rewind元に戻す：コードと会話を以前の状態へ
  • /autocompactコンテキストがどれだけ埋まったら自動圧縮するかを設定します（例：500k）。auto でモデルの既定値に戻ります。ユーザー設定に保存され、すぐ反映されます。
  • /branch今の時点で会話の分岐を作って切り替え、別の方向を試せます。元の会話は残り /resume で戻れます。（Git のブランチではなく会話の分岐です。）
