/design-login

英文 design login ＝ 設計登入

當 /design-sync 或 /design consent 要求時，用你的 claude.ai 帳號為 /design-sync 授權設計系統存取。

最佳用法

/design-sync 要求你登入時執行。

相關指令 · 網頁、投影片與設計

  • /artifact-capabilities載入 artifact 執行時功能的參考資料，例如呼叫連接器或提供下載，以及你的帳號有哪些功能。Claude 通常會自己載入。
  • /artifact-diagramming載入在 artifact 中繪製圖表的指引：什麼時候圖有幫助、要畫什麼，以及如何寫出在淺色和深色主題下都清楚的 SVG。
  • /artifacts列出你擁有或別人分享給你的 artifact，然後可以接入其中一個、開啟它，或複製連結。只在支援 artifact 的環境中可用。
  • /dataviz圖表設計指引：選擇圖表形式、依角色分配顏色，並用內建的腳本檢查配色是否色盲友善、對比是否足夠。
  • /design在同一張畫布上以多個畫板草擬 UI 設計稿、操作流程、到達頁或海報（Claude Design artifact）；可在桌面瀏覽器中編輯，並匯出 PNG 或 PDF。Bedrock、Vertex 及其他第三方平台無法使用。
  • /design consent授予或撤回 Claude 對 Claude Design 的存取權。當 Claude 要求你執行 /design consent 時，請自己輸入。
  • /design-sync把你儲存庫中的 React 設計系統轉換並上傳到 Claude Design，讓設計使用你真正的元件。大型儲存庫第一次同步可能要好幾個小時。上傳目標是獨立的 claude.ai/design 網站，該網站將在 2026 年 12 月 14 日前關閉。
  • /slides根據你的說明製作一份 Claude Slides artifact。需要支援 artifact 的工作階段，以及可以使用 Slides 範本的帳號。
