/deep-research<question>

英文 deep research ＝ 深度研究

工作流程

內建的工作流程：大量搜尋網路、抓取並交叉比對來源，然後寫出附有引用的報告。在背景執行。

最佳用法

/deep-research 比較主流 AI 影片工具的價格和品質。

相關指令 · 自動化與排程

  • /loop依固定間隔重複執行提示
  • /autofix-pr開啟一個雲端工作階段，盯著目前分支的 PR，在 CI 失敗或有審查意見時推送修正。需要 gh CLI 和雲端工作階段。
  • /schedule透過引導式對話，建立、更新、列出或執行雲端排程工作（以前叫 routines）。使用 Console API 金鑰時無法使用。
