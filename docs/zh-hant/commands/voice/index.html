/voice[hold|tap|off]

英文 voice ＝ 語音

開關語音輸入，或設定模式（hold、tap）。需要 Claude.ai 帳號。

最佳用法

用說的下指示，不必打字。

相關指令 · 設定與介面

  • /color設定這次工作階段輸入列的顏色：red、blue、green、yellow、purple、orange、pink 或 cyan；default 恢復預設，不加參數則隨機選一個顏色。
  • /config開啟設定畫面，調整主題、模型、輸出風格等，或直接設定 key=value，例如 /config theme=dark。/config --help 會列出可用的鍵。
  • /focus切換一種只顯示你最後一則提示、一行工具摘要和最終回答的畫面。只限全螢幕渲染模式。
  • /keybindings開啟你的快速鍵設定檔。
  • /scroll-speed調整滑鼠滾輪的捲動速度。只限全螢幕渲染模式；JetBrains 終端機中無法使用。
  • /statusline設定狀態列；描述你想顯示的內容，或不加參數，從你的 shell 提示字元自動產生。
  • /terminal-setup在 VS Code、Cursor、Devin Desktop、Alacritty 或 Zed 中設定 Shift+Enter 換行；在 Apple 終端機中啟用 Option+Enter 並關閉提示音；在 iTerm2 中開啟剪貼簿存取，讓 /copy 可以使用。
  • /theme更換配色主題：auto、淺色和深色、色盲友善、ANSI 和自訂主題。
