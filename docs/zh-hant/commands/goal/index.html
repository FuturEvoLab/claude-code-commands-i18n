/goal[condition|clear]

英文 goal ＝ 目標

設定目標：Claude 會跨多輪持續工作，直到條件達成或目標被清除。不加參數會顯示目前的目標；clear（或 stop、off 等）會移除目標。

最佳用法

/goal 所有測試都通過，然後讓它反覆修改，直到測試全部通過。

適用情境

  • 重複執行或依排程執行工作/loop → /schedule → /goal

相關指令 · 對話與上下文

  • /clear開始全新對話（舊對話之後仍可接續）
  • /compact把很長的對話整理成摘要，騰出空間
  • /context查看是什麼佔滿了上下文
  • /plan先看計畫；經你核准後才會修改
  • /resume回到之前的對話
  • /rewind復原：把程式碼和對話退回去
  • /autocompact設定上下文視窗用到多滿時自動壓縮，例如 500k；auto 會恢復成依模型調整的預設值。會儲存到使用者設定並立即生效。
  • /branch在目前位置為對話建立一個分支並切換過去；原本的對話會保留，可以用 /resume 回去。（這是對話分支，不是 Git 分支。）
