/setup-vertex

英文 set up Vertex ＝ 設定 Google Cloud

透過精靈設定 Google Cloud 的 Agent Platform。設定 CLAUDE_CODE_USE_VERTEX=1 之前不會出現在選單中；需要完整輸入。

最佳用法

你的公司透過 Google Cloud 使用 Claude 時。

相關指令 · 雲端、遠端與其他裝置

  • /desktop在 Claude Code 桌面版 App 中繼續這次工作階段。需要 macOS 或 x64 Windows，以及 Claude 訂閱。
  • /mobile顯示下載 Claude 手機 App 的 QR code。
  • /remote-control讓這次工作階段可以從 claude.ai 進行遠端控制（Remote Control）。需要 claude.ai 訂閱。
  • /remote-env選擇從 CLI 啟動雲端工作階段時預設使用的雲端環境。
  • /setup-bedrock透過精靈設定 Amazon Bedrock 的驗證、區域和固定使用的模型。設定 CLAUDE_CODE_USE_BEDROCK=1 之前不會出現在選單中；需要完整輸入。
  • /teleport把雲端工作階段拉到這個終端機，同時取得它的分支和對話。需要 claude.ai 訂閱。
  • /web-setup用你本機的 gh 登入資訊，為雲端工作階段連接 GitHub。
