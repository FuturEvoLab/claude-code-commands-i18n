/resume[session]

回到之前的對話

英文 resume ＝ 繼續、恢復

★ 新手推薦

用 ID 或名稱恢復之前的對話，或開啟工作階段清單。背景工作階段會標示為 bg。

最佳用法

昨天做到一半就闔上筆電：執行 /resume，選擇昨天的對話。

別名

/continue

適用情境

  • 從頭開始一件不相關的工作/clear → /resume
  • 繼續昨天沒做完的工作/resume → /rename → /recap

相關指令 · 對話與上下文

  • /clear開始全新對話（舊對話之後仍可接續）
  • /compact把很長的對話整理成摘要，騰出空間
  • /context查看是什麼佔滿了上下文
  • /plan先看計畫；經你核准後才會修改
  • /rewind復原：把程式碼和對話退回去
  • /autocompact設定上下文視窗用到多滿時自動壓縮，例如 500k；auto 會恢復成依模型調整的預設值。會儲存到使用者設定並立即生效。
  • /branch在目前位置為對話建立一個分支並切換過去；原本的對話會保留，可以用 /resume 回去。（這是對話分支，不是 Git 分支。）
  • /btw針對目前的工作階段問一個旁支問題，不會加入對話紀錄。不加問題則顯示你最近一次的旁支問題。
