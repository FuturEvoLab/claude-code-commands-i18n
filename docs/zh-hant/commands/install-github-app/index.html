/install-github-app

英文 install GitHub app ＝ 安裝 GitHub 應用程式

↗ 會傳送到外部⚑ 會變更安全設定

為儲存庫安裝 Claude GitHub App，也可以順便設定 GitHub Actions 工作流程和機密（secrets）。只適用於 github.com。

最佳用法

想在 issue 和 PR 中提及 Claude，讓它在那裡工作。

安全標記

↗ 會傳送到外部: 會把對話、程式碼或留言傳送到其他服務（Anthropic、GitHub、雲端工作階段、你瀏覽器中的網站），或推送到遠端。請先確認什麼內容會送到哪裡。

⚑ 會變更安全設定: 會改變 Claude 不必詢問就能做的事，或其他安全設定。只允許你了解且信任的操作。
