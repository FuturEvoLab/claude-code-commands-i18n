/model[model]

切換模型

英文 model ＝ 模型

★ 新手推薦

切換模型，並儲存為新工作階段的預設值。不加參數會開啟選擇器；支援的模型可以用左右鍵調整思考力度；在某一列按 s 則只在這次工作階段切換。

最佳用法

小修改用比較快的模型；遇到難纏的 bug 時用 /model opus 切換。

適用情境

  • 大幅修改前，先看計畫/plan → /effort → /model
  • 省錢、省用量/usage → /model → /effort → /context

相關指令 · 模型與推理

  • /advisor開啟或關閉顧問工具，在關鍵時刻詢問第二個模型的意見。可以填 fable、opus、sonnet 或完整的模型 ID（fable 需要存取權限）。不加參數會開啟選擇器。
  • /effort設定思考力度：low 到 xhigh、max 或 auto；status 會顯示目前的值。max 只在這次工作階段有效。ultracode on|off 可開關 ultracode。
  • /fast開關快速模式（同一個模型，輸出更快）。可以在回答途中切換，但正在進行的這一輪仍以原本的速度完成。價格請參考官方 fast mode 說明。
  • /output-style列出輸出風格或切換到其中一種，例如 /output-style concise。
