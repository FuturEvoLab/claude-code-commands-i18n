/advisor[model|off]

英文 advisor ＝ 顧問

開啟或關閉顧問工具，在關鍵時刻詢問第二個模型的意見。可以填 fable、opus、sonnet 或完整的模型 ID（fable 需要存取權限）。不加參數會開啟選擇器。

最佳用法

平常用較快的模型工作，但在關鍵決策時取得更強模型的第二意見：/advisor opus。

相關指令 · 模型與推理

  • /model切換模型
  • /effort設定思考力度：low 到 xhigh、max 或 auto；status 會顯示目前的值。max 只在這次工作階段有效。ultracode on|off 可開關 ultracode。
  • /fast開關快速模式（同一個模型，輸出更快）。可以在回答途中切換，但正在進行的這一輪仍以原本的速度完成。價格請參考官方 fast mode 說明。
  • /output-style列出輸出風格或切換到其中一種，例如 /output-style concise。
