/copy[N]

英文 copy ＝ 複製

把最後一則回答複製到剪貼簿；/copy 2 複製倒數第二則。有程式碼區塊時，會出現選擇器讓你只複製其中一塊；按 w 改為寫入檔案（透過 SSH 連線時很有用）。

最佳用法

Claude 寫好一段程式碼或指令：/copy，再貼到你需要的地方。

相關指令 · 對話與上下文

  • /clear開始全新對話（舊對話之後仍可接續）
  • /compact把很長的對話整理成摘要，騰出空間
  • /context查看是什麼佔滿了上下文
  • /plan先看計畫；經你核准後才會修改
  • /resume回到之前的對話
  • /rewind復原：把程式碼和對話退回去
  • /autocompact設定上下文視窗用到多滿時自動壓縮，例如 500k；auto 會恢復成依模型調整的預設值。會儲存到使用者設定並立即生效。
  • /branch在目前位置為對話建立一個分支並切換過去；原本的對話會保留，可以用 /resume 回去。（這是對話分支，不是 Git 分支。）
