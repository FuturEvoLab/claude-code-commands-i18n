/update-config[request]

英文 update config ＝ 更新設定

技能⚑ 會變更安全設定

描述你想要的設定變更（允許某個指令、設定環境變數、加入 hook），Claude 就會編輯對應的 settings.json。主題和模型請用 /config。

最佳用法

/update-config 每次編輯檔案後執行 prettier。

安全標記

⚑ 會變更安全設定: 會改變 Claude 不必詢問就能做的事，或其他安全設定。只允許你了解且信任的操作。

相關指令 · 權限與安全

  • /permissions決定 Claude 不必詢問就能做哪些事
  • /auto-mode-setup根據你的專案和最近的工作階段，草擬 autoMode.environment 項目，讓你檢查後儲存。有版本和方案的限制。
  • /fewer-permission-prompts掃描對話紀錄中常見的唯讀 Bash 和 MCP 呼叫，依優先順序把允許清單加到專案的 .claude/settings.json。
  • /hooks檢視 hook 設定。
  • /privacy-settings檢視和更新隱私設定。只限 Pro、Max 和 Ultra。
  • /sandbox開關沙箱模式，只在支援的平台上可用。
