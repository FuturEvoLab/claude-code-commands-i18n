/simplify[target]

英文 simplify ＝ 簡化

技能⇄ 大範圍修改檔案

4 個代理平行檢查修改過的程式碼：能否重複利用、能否更簡單、效率、抽象層級，然後直接套用修正。它不會找正確性的 bug；那要用 /code-review。

最佳用法

功能已經能正常運作，想讓程式碼更乾淨：/simplify。

安全標記

⇄ 大範圍修改檔案: 可能一次修改或還原很多檔案。請先提交或備份，之後用 /diff 檢查。

相關指令 · 審查與驗證

  • /code-review提交前檢查 bug，也可以順便修正
  • /run啟動並操作你專案的應用程式，看看修改實際運作的樣子。
  • /run-skill-generator為這個專案寫一個專屬技能，教 /run 和 /verify 如何從乾淨的環境建置、啟動和操作你的應用程式。
  • /security-review比對你的分支與 origin 預設分支之間的差異，找出漏洞，例如注入、驗證問題和資料外洩。需要名為 origin 的遠端。
  • /ultrareview在雲端沙箱中用多個代理深度審查。建議的寫法是 /code-review ultra；/ultrareview 是別名。Pro、Max 和 Ultra 包含 3 次免費執行，之後需要用量額度。
  • /verify實際建置、執行並觀察你的應用程式，確認修改有效，而不是只依賴測試或型別檢查。只有在你呼叫時才會執行。
