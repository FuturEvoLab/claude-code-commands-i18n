/schedule[description]

英文 schedule ＝ 排程

透過引導式對話，建立、更新、列出或執行雲端排程工作（以前叫 routines）。使用 Console API 金鑰時無法使用。

最佳用法

/schedule 每個工作日早上 9 點，整理儲存庫中新的 issue。

別名

/routines

適用情境

  • 重複執行或依排程執行工作/loop → /schedule → /goal

相關指令 · 自動化與排程

  • /loop依固定間隔重複執行提示
  • /autofix-pr開啟一個雲端工作階段，盯著目前分支的 PR，在 CI 失敗或有審查意見時推送修正。需要 gh CLI 和雲端工作階段。
  • /deep-research內建的工作流程：大量搜尋網路、抓取並交叉比對來源，然後寫出附有引用的報告。在背景執行。
