/mcp[reconnect (<server>|all)|enable|disable [<server>|all]]

管理外部工具的連線

英文 MCP (Model Context Protocol) ＝ MCP（Model Context Protocol，模型上下文協定）

★ 新手推薦

管理 MCP 伺服器連線和 OAuth。不加參數會開啟清單；reconnect、enable 或 disable 加上伺服器名稱或 all 可直接操作。

最佳用法

連接器失敗或需要驗證：/mcp reconnect all。

適用情境

  • 連接工具或增加新能力/mcp → /plugin → /skills

相關指令 · 外掛、技能與整合

  • /chrome設定 Claude in Chrome。
  • /claude-api載入適合你專案程式語言的 Claude API 和 Managed Agents 參考資料；程式碼匯入 anthropic 時會自動啟用。子指令包括 migrate、upgrade、api-version、cost-optimize、latency-optimize、build-eval、prompt-audit。
  • /claude-in-chrome透過 Claude in Chrome 讓 Claude 在你的瀏覽器中執行工作，例如測試網頁或讀取主控台紀錄。需要啟用 Chrome 整合（例如 claude --chrome）。
  • /ide管理 IDE 整合並顯示狀態。
  • /install-github-app為儲存庫安裝 Claude GitHub App，也可以順便設定 GitHub Actions 工作流程和機密（secrets）。只適用於 github.com。
  • /install-slack-app透過瀏覽器的 OAuth 流程安裝 Claude Slack 應用程式。
  • /plugin管理外掛。不加參數會開啟選單；list、install、enable、disable 可直接操作。如果安裝摘要有提示，請執行 /reload-plugins。
  • /plugin-authoring載入撰寫 mod 的參考資料。這是內建外掛提供的技能，可以在 /plugin 中關閉。
