/passes

英文 passes ＝ 體驗券

和朋友分享一週免費的 Claude Code；只有符合資格的帳號才會顯示。

最佳用法

邀請朋友試用。

相關指令 · 帳號與用量

  • /usage查看費用和方案上限
  • /login登入你的 Anthropic 帳號。
  • /logout登出你的 Anthropic 帳號。
  • /rate-limit-options當 claude.ai 的用量上限擋住你時，顯示可以繼續工作的方法：等待並自動繼續、加購用量額度，或升級。需要 claude.ai 訂閱。
  • /status開啟設定的「狀態」分頁：版本、模型、帳號、連線狀況。Claude 正在回答時也能使用。
  • /upgrade在瀏覽器中開啟升級頁面。
  • /usage-credits設定或申請用量額度；沒有帳單權限的 Team 和 Enterprise 成員會向管理員送出申請。以前叫 /extra-usage。
