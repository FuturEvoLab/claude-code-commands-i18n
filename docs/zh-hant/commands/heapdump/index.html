/heapdump

英文 heap dump ＝ 堆積傾印（記憶體快照）

⚿ 可能洩漏機密

把 heap 快照和記憶體明細寫到桌面，用來診斷記憶體用量過高的問題。只分享 -diagnostics.json；.heapsnapshot 含有你的對話和登入憑證。選單中不會顯示。

最佳用法

回報記憶體用量暴增的問題。

安全標記

⚿ 可能洩漏機密: 輸出內容（檔案、剪貼簿、報告）可能含有對話文字、金鑰、密碼或個人資料。分享前請檢查並刪除敏感內容。

相關指令 · 診斷與意見回饋

  • /doctor出問題時做一次健檢
  • /help顯示說明和所有指令
  • /powerup用互動課程學習功能
  • /bug回報 bug 或分享你的對話；你可以選擇要附上多少紀錄，而且在送出任何內容前都會請你確認。
  • /debug從現在開始啟用除錯紀錄，並透過閱讀工作階段的除錯紀錄來排查問題。可以附上問題描述。
  • /exit離開 CLI。在已連接的背景工作階段中，它只會中斷連接，工作階段會繼續執行。
  • /feedback用和 /bug 相同的對話框和同意步驟送出產品意見。
  • /release-notes在版本選擇器中查看更新紀錄；內容會顯示出來，但不會進入 Claude 的上下文。
