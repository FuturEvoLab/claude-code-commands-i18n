/permissions

決定 Claude 不必詢問就能做哪些事

英文 permissions ＝ 權限

★ 新手推薦⚑ 會變更安全設定

管理工具的允許、詢問和拒絕規則：依範圍檢視、新增或移除規則、管理工作資料夾，查看「Recently blocked」分頁（自動模式擋下的操作）和分類器規則。

最佳用法

每次都要核准 npm test 很煩：在這裡把它設為允許。

別名

/allowed-tools

安全標記

⚑ 會變更安全設定: 會改變 Claude 不必詢問就能做的事，或其他安全設定。只允許你了解且信任的操作。

適用情境

  • 權限確認提示太多/permissions → /fewer-permission-prompts
