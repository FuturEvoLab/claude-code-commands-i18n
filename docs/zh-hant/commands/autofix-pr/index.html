/autofix-pr[prompt]

英文 auto-fix PR ＝ 自動修正 PR

↗ 會傳送到外部

開啟一個雲端工作階段，盯著目前分支的 PR，在 CI 失敗或有審查意見時推送修正。需要 gh CLI 和雲端工作階段。

最佳用法

/autofix-pr 只修 lint 和型別錯誤。

安全標記

↗ 會傳送到外部: 會把對話、程式碼或留言傳送到其他服務（Anthropic、GitHub、雲端工作階段、你瀏覽器中的網站），或推送到遠端。請先確認什麼內容會送到哪裡。

相關指令 · 自動化與排程

  • /deep-research內建的工作流程：大量搜尋網路、抓取並交叉比對來源，然後寫出附有引用的報告。在背景執行。
  • /schedule透過引導式對話，建立、更新、列出或執行雲端排程工作（以前叫 routines）。使用 Console API 金鑰時無法使用。
