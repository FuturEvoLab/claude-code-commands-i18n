/context[all]

查看是什麼佔滿了上下文

英文 context ＝ 上下文（Claude 目前能「記住」的內容）

★ 新手推薦

用彩色方格圖顯示上下文的使用量，並提供最佳化建議和容量警告。all 會展開每一項的明細。

最佳用法

覺得 Claude 變健忘或用量增加很快時，執行 /context，看看是不是大型檔案或工具輸出佔滿了視窗。

適用情境

  • 對話太長，Claude 變慢或開始忘東忘西/context → /compact → /autocompact
  • 省錢、省用量/usage → /model → /effort → /context

相關指令 · 對話與上下文

  • /clear開始全新對話（舊對話之後仍可接續）
  • /compact把很長的對話整理成摘要，騰出空間
  • /plan先看計畫；經你核准後才會修改
  • /resume回到之前的對話
  • /rewind復原：把程式碼和對話退回去
  • /autocompact設定上下文視窗用到多滿時自動壓縮，例如 500k；auto 會恢復成依模型調整的預設值。會儲存到使用者設定並立即生效。
  • /branch在目前位置為對話建立一個分支並切換過去；原本的對話會保留，可以用 /resume 回去。（這是對話分支，不是 Git 分支。）
  • /btw針對目前的工作階段問一個旁支問題，不會加入對話紀錄。不加問題則顯示你最近一次的旁支問題。
