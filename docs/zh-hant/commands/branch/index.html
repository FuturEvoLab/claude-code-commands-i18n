/branch[name]

英文 branch ＝ 分支

在目前位置為對話建立一個分支並切換過去；原本的對話會保留，可以用 /resume 回去。（這是對話分支，不是 Git 分支。）

最佳用法

兩種做法拿不定主意：/branch 試試方案B；如果不行，就回去繼續方案 A。

相關指令 · 對話與上下文

  • /clear開始全新對話（舊對話之後仍可接續）
  • /compact把很長的對話整理成摘要，騰出空間
  • /context查看是什麼佔滿了上下文
  • /plan先看計畫；經你核准後才會修改
  • /resume回到之前的對話
  • /rewind復原：把程式碼和對話退回去
  • /autocompact設定上下文視窗用到多滿時自動壓縮，例如 500k；auto 會恢復成依模型調整的預設值。會儲存到使用者設定並立即生效。
  • /btw針對目前的工作階段問一個旁支問題，不會加入對話紀錄。不加問題則顯示你最近一次的旁支問題。
