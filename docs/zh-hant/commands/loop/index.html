/loop[interval] [prompt]

依固定間隔重複執行提示

英文 loop ＝ 迴圈

★ 新手推薦技能

在工作階段開著的期間反覆執行一個提示。不寫間隔則由 Claude 自己決定節奏；不寫提示則執行內建的維護提示或你的 loop.md。

最佳用法

/loop 5m 檢查部署是否完成。如果要在電腦關機時也繼續執行，請用 /schedule。

別名

/proactive

適用情境

  • 重複執行或依排程執行工作/loop → /schedule → /goal

  • /schedule透過引導式對話，建立、更新、列出或執行雲端排程工作（以前叫 routines）。使用 Console API 金鑰時無法使用。
