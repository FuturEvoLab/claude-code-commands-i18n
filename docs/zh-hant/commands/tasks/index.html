/tasks

英文 tasks ＝ 工作、任務

檢視並管理這次工作階段中的背景工作，包括已完成的子代理。

最佳用法

用 /tasks 查看背景測試或子代理的進度。

別名

/bashes

適用情境

  • 同時做好幾件事，或放到背景執行/fork → /subtask → /background → /tasks → /batch

相關指令 · 平行與背景工作

  • /agents顯示一則提醒：請直接要求 Claude 建立或管理子代理，或直接編輯 .claude/agents/。在 v2.1.197 及更早的版本中，會開啟互動式管理介面。
  • /background把工作階段轉為背景代理繼續執行，並釋放終端機。可以先再傳一條指示。用 claude agents 查看狀態。
  • /batch平行處理大規模修改：先研究程式碼，把工作拆成 5～30 個獨立單元並提出計畫；經你核准後，每個單元由一個背景子代理在自己的 worktree 中實作並測試。需要 git 儲存庫或 WorktreeCreate hook。
  • /fork把對話複製成一個新的背景工作階段，你可以繼續在這裡工作。附上指示的話，副本會立刻開始；通常會先讓它建立自己的 worktree。
  • /list-agents列出 Claude 可以傳訊息的子代理、團隊成員和其他工作階段，以及各自要用的名稱。只在啟用跨工作階段訊息時可用。
  • /stop停止你目前連接的背景工作階段；紀錄和 worktree 會保留。只想中斷連接而不停止，請用 /exit 或按 ←。
  • /subtask派出一個分岔的子代理，它會繼承對話內容，並把結果回報到這裡。與 /fork 的差別：/subtask 會把結果回報到這裡，/fork 則會另開一個獨立的工作階段。
  • /workflow-authoring載入撰寫動態工作流程腳本的參考資料。Claude 通常會自己載入；手動編輯已儲存的腳本前可以先執行。只在啟用動態工作流程時可用。
