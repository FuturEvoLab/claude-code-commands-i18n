/doctor[prompt-audit [path]]

出問題時做一次健檢

英文 doctor ＝ 醫生（健檢）

★ 新手推薦技能

為安裝、設定、擴充功能和 CLAUDE.md 做健檢，並提出修正方案，經你確認後由 Claude 套用。prompt-audit 則改為審查你的說明內容。

最佳用法

感覺哪裡怪怪的：先執行 /doctor。

別名

/checkup

適用情境

  • Claude Code 本身運作異常/doctor → /status → /debug → /bug

相關指令 · 診斷與意見回饋

  • /help顯示說明和所有指令
  • /powerup用互動課程學習功能
  • /bug回報 bug 或分享你的對話；你可以選擇要附上多少紀錄，而且在送出任何內容前都會請你確認。
  • /debug從現在開始啟用除錯紀錄，並透過閱讀工作階段的除錯紀錄來排查問題。可以附上問題描述。
  • /exit離開 CLI。在已連接的背景工作階段中，它只會中斷連接，工作階段會繼續執行。
  • /feedback用和 /bug 相同的對話框和同意步驟送出產品意見。
  • /heapdump把 heap 快照和記憶體明細寫到桌面，用來診斷記憶體用量過高的問題。只分享 -diagnostics.json；.heapsnapshot 含有你的對話和登入憑證。選單中不會顯示。
  • /release-notes在版本選擇器中查看更新紀錄；內容會顯示出來，但不會進入 Claude 的上下文。
