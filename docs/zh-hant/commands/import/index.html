/import[codex|gemini|cursor] [--dry-run] [--yes]

英文 import ＝ 匯入

⇄ 大範圍修改檔案

從 OpenAI Codex、Gemini CLI 或 Cursor 匯入說明檔、MCP 伺服器、指令、子代理和技能。--dry-run 只預覽。部分雲端供應商無法使用；從 Cursor 匯入需要 v2.1.265+。

最佳用法

從 Cursor 轉過來：先執行 /import cursor --dry-run，再正式匯入。

安全標記

⇄ 大範圍修改檔案: 可能一次修改或還原很多檔案。請先提交或備份，之後用 /diff 檢查。

相關指令 · 專案與檔案

  • /init建立專案的 CLAUDE.md
  • /add-dir在這次工作階段中額外允許存取另一個工作資料夾，目前位置不會改變。輸入部分路徑後可以按 Tab 自動完成。新增的資料夾裡大部分的 .claude/ 設定不會被讀取，而且大多數網路路徑無法新增。
  • /cd把工作階段移到新的工作資料夾，對話會保留。和 /add-dir 不同，/cd 會改變工作階段所在的位置。
  • /diff檢視工作目錄中的修改，包括 Claude 到目前為止做的編輯。
  • /insights為你在這台電腦上最近的工作階段產生一份 HTML 報告：專案、使用習慣、容易出問題的地方、值得嘗試的功能。雲端工作階段中無法使用。
  • /team-onboarding分析你過去 30 天的工作階段、指令和 MCP 使用情況，寫出一份 Markdown 指南，讓同事可以貼上當作第一則訊息。
