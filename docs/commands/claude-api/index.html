/claude-api[subcommand]

Skill

Loads Claude API and Managed Agents reference for your project's language; activates automatically when code imports anthropic. Subcommands include migrate, upgrade, api-version, cost-optimize, latency-optimize, build-eval, prompt-audit.

Best use

Cut API spend in your app: /claude-api cost-optimize.
