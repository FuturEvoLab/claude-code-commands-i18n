/code-review[low|medium|high|xhigh|max|ultra] [--fix] [--comment] [--max-findings n|all|default] [pr#|branch|path]

Check for bugs before committing, optionally fix them

★ Start hereSkill¥ May cost money↗ Sends data out⇄ Broad file changes

Reviews the current diff, or a PR, branch or path, for correctness bugs. --fix applies findings, --comment posts to the GitHub PR or GitLab MR, ultra runs a deep cloud review.

Best use

Before committing: /code-review high --fix. For a PR: /code-review high 1234.

Aliases

/review

Safety labels

¥ May cost money: Can consume paid usage or incur extra charges. Check /usage and the official pricing first.

↗ Sends data out: Sends conversation, code or comments to another service (Anthropic, GitHub, cloud sessions, sites in your browser) or pushes to a remote. Check what goes where first.

⇄ Broad file changes: Can change or revert many files at once. Commit or back up first, and review with /diff afterwards.

Used in these situations

  • Check work before committing or shipping/diff → /code-review → /security-review → /verify
