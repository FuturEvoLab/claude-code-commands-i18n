/skills

Lists skills with filtering. t sorts by token count, Space/Enter cycles a skill's visibility to Claude and the / menu, Esc saves and closes.

Best use

Too many skills: /skills, press t, hide the heavy unused ones.

Used in these situations

  • Connect tools or add new abilities/mcp → /plugin → /skills

Related commands · Plugins, skills & integrations

  • /mcpManage external tool connections
  • /chromeConfigures Claude in Chrome settings.
  • /claude-apiLoads Claude API and Managed Agents reference for your project's language; activates automatically when code imports anthropic.
  • /claude-in-chromeHas Claude carry out a task in your browser through Claude in Chrome, such as testing a page or reading console logs.
  • /ideManages IDE integrations and shows status.
  • /install-github-appInstalls the Claude GitHub App for a repository, optionally setting up GitHub Actions workflows and secrets.
  • /install-slack-appInstalls the Claude Slack app via a browser OAuth flow.
  • /pluginManages plugins.
