/bug[report]

↗ Sends data out⚿ May expose secrets

Reports a bug or shares your conversation; you choose how much history to include and confirm before anything is sent.

Best use

When Claude Code itself misbehaves.

Aliases

/share

Safety labels

↗ Sends data out: Sends conversation, code or comments to another service (Anthropic, GitHub, cloud sessions, sites in your browser) or pushes to a remote. Check what goes where first.

⚿ May expose secrets: Output (files, clipboard, reports) can contain conversation text, keys, passwords or personal data. Review and redact before sharing.

Used in these situations

  • Claude Code itself is misbehaving/doctor → /status → /debug → /bug

Related commands · Diagnostics & feedback

  • /doctorRun a checkup when something is wrong
  • /helpShow help and all commands
  • /powerupLearn features through interactive lessons
  • /debugEnables debug logging from this point and troubleshoots by reading the session debug log.
  • /exitExits the CLI.
  • /feedbackSends product feedback using the same dialog and consent step as /bug.
  • /heapdumpWrites a heap snapshot and memory breakdown to the Desktop for diagnosing high memory.
  • /release-notesViews the changelog in a version picker; notes appear without entering Claude's context.
