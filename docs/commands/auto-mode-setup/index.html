/auto-mode-setup

⚑ Changes safety settings

Drafts autoMode.environment entries from your project and recent sessions for you to review and save. Has version and plan requirements.

Best use

When auto mode keeps blocking routine actions.

Safety labels

⚑ Changes safety settings: Changes what Claude may do without asking, or other safety settings. Only allow actions you understand and trust.
