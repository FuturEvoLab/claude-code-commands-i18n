/memory

Edits CLAUDE.md memory files, toggles auto memory, and shows auto memory entries.

Best use

Want every answer in your language: open /memory and add a line such as “Always reply in Japanese.”

Used in these situations

  • Make Claude always answer in my language/init → /memory

Related commands · Conversation & context

  • /clearStart a fresh conversation (the old one stays resumable)
  • /compactSummarize a long conversation to free space
  • /contextSee what is filling the context window
  • /planGet a plan first; edits wait for your approval
  • /resumeGo back to an earlier conversation
  • /rewindUndo: roll code and conversation back
  • /autocompactSets how full the context window gets before automatic compaction, e.g.
  • /branchCreates a branch of the conversation at this point and switches into it; the original is preserved and reachable via /resume.
