/permissions

Decide what Claude may do without asking

★ Start here⚑ Changes safety settings

Manages allow, ask and deny rules for tools: view by scope, add or remove rules, manage working directories, and check the Recently blocked tab (calls auto mode refused) and classifier rules.

Best use

Tired of approving npm test every time: allow it here.

Aliases

/allowed-tools

Safety labels

⚑ Changes safety settings: Changes what Claude may do without asking, or other safety settings. Only allow actions you understand and trust.

Used in these situations

  • Too many permission prompts/permissions → /fewer-permission-prompts

Related commands · Permissions & safety
