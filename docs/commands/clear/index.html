/clear[name]

Start a fresh conversation (the old one stays resumable)

★ Start here

Starts a new conversation with empty context while keeping project memory. The previous conversation is kept and can be reopened with /resume; pass a name to label it in the picker.

Best use

When you finish one feature and move to an unrelated task: /clear login-feature. Old context stops interfering and usage drops.

Aliases

/reset · /new

Used in these situations

  • Start an unrelated task from scratch/clear → /resume
