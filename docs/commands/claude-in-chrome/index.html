/claude-in-chrome[task]

Skill↗ Sends data out

Has Claude carry out a task in your browser through Claude in Chrome, such as testing a page or reading console logs. Requires Chrome integration (e.g. claude --chrome).

Best use

/claude-in-chrome test the sign-up flow on my local site and report errors.

Safety labels

↗ Sends data out: Sends conversation, code or comments to another service (Anthropic, GitHub, cloud sessions, sites in your browser) or pushes to a remote. Check what goes where first.
