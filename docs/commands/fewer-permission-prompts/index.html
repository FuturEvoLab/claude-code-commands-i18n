/fewer-permission-prompts

Skill⚑ Changes safety settings

Scans transcripts for common read-only Bash and MCP calls and adds a prioritized allowlist to project .claude/settings.json.

Best use

Run once when approval prompts keep interrupting you.

Safety labels

⚑ Changes safety settings: Changes what Claude may do without asking, or other safety settings. Only allow actions you understand and trust.

Used in these situations

  • Too many permission prompts/permissions → /fewer-permission-prompts
