/remote-control

↗ Sends data out

Makes this session available for Remote Control from claude.ai. Requires a claude.ai subscription.

Best use

Leave the task running and steer it from your phone: /rc.

Aliases

/rc

Safety labels

↗ Sends data out: Sends conversation, code or comments to another service (Anthropic, GitHub, cloud sessions, sites in your browser) or pushes to a remote. Check what goes where first.

Used in these situations

  • Leave the computer and continue on my phone/remote-control → /mobile → /desktop

Related commands · Cloud, remote & other devices

  • /desktopContinues the session in the Claude Code Desktop app.
  • /mobileShows a QR code to download the Claude mobile app.
  • /remote-envChooses the default cloud environment for cloud sessions started from the CLI.
  • /setup-bedrockConfigures Amazon Bedrock auth, region and model pins via a wizard.
  • /setup-vertexConfigures Google Cloud's Agent Platform via a wizard.
  • /teleportPulls a cloud session into this terminal, fetching its branch and conversation.
  • /web-setupConnects GitHub for cloud sessions using your local gh credentials.
