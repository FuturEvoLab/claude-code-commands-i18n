/restart

v2.1.288+

Restarts Claude Code and resumes the session to apply an installed update. Requires Pro, Max or Ultra and a native macOS or Linux install (not WSL).

Best use

When the footer offers it after an update.

Aliases

/update

Related commands · Diagnostics & feedback

  • /debugEnables debug logging from this point and troubleshoots by reading the session debug log.
