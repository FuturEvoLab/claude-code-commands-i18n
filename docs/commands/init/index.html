/init

Create the project's CLAUDE.md

★ Start here

Initializes the project with a CLAUDE.md guide that every new session reads. Offers /import if it finds Codex or Gemini CLI configuration.

Best use

First thing in a new repo: /init, then refine it with /memory.

Used in these situations

  • Make Claude always answer in my language/init → /memory

Related commands · Project & files

  • /add-dirAdds a working directory for file access this session without moving.
  • /cdMoves the session to a new working directory, keeping the conversation.
  • /diffReviews changes in your working tree, including Claude's edits so far.
  • /importImports instruction files, MCP servers, commands, subagents and skills from OpenAI Codex, Gemini CLI or Cursor.
  • /insightsGenerates an HTML report of your recent sessions on this machine: projects, habits, where things go wrong, features to try.
  • /team-onboardingAnalyzes your last 30 days of sessions, commands and MCP usage and writes a Markdown guide a teammate can paste as their first message.
