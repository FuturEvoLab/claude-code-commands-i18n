/security-review

Analyzes your branch's diff against origin's default branch for vulnerabilities such as injection, auth issues and data exposure. Needs an origin remote.

Best use

Before shipping anything touching auth, payments or user data.

Used in these situations

  • Check work before committing or shipping/diff → /code-review → /security-review → /verify

Related commands · Review & verification

  • /code-reviewCheck for bugs before committing, optionally fix them
  • /runLaunches and drives your project's app to see a change working.
  • /run-skill-generatorWrites a per-project skill that teaches /run and /verify how to build, launch and drive your app from a clean environment.
  • /simplifyFour parallel agents review changed code for reuse, simplification, efficiency and abstraction level, then apply fixes.
  • /ultrareviewDeep multi-agent review in a cloud sandbox.
  • /verifyBuilds, runs and observes your app to confirm a change works, rather than relying on tests or type checks.
