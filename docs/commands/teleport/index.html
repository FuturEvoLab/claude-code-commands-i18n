/teleport

Pulls a cloud session into this terminal, fetching its branch and conversation. Requires a claude.ai subscription.

Best use

Continue a web-started task locally.

Aliases

/tp

Related commands · Cloud, remote & other devices

  • /desktopContinues the session in the Claude Code Desktop app.
  • /mobileShows a QR code to download the Claude mobile app.
  • /remote-controlMakes this session available for Remote Control from claude.ai.
  • /remote-envChooses the default cloud environment for cloud sessions started from the CLI.
  • /setup-bedrockConfigures Amazon Bedrock auth, region and model pins via a wizard.
  • /setup-vertexConfigures Google Cloud's Agent Platform via a wizard.
  • /web-setupConnects GitHub for cloud sessions using your local gh credentials.
