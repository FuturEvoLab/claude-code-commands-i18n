/terminal-setup

Installs Shift+Enter for newlines in VS Code, Cursor, Devin Desktop, Alacritty or Zed; in Apple Terminal enables Option+Enter and disables the bell; in iTerm2 enables clipboard access for /copy.

Best use

Enter keeps sending half-written prompts: run this once.
