/model[model]

Switch models

★ Start here

Switches the model and saves it as the default for new sessions. No argument opens a picker; left/right adjusts effort on supported models; press s on a row to switch for this session only.

Best use

Use a faster model for small edits; switch with /model opus when a bug gets hard.

Used in these situations

  • See a plan before a big change/plan → /effort → /model
  • Spend less money and usage/usage → /model → /effort → /context

Related commands · Model & reasoning

  • /advisorEnables or disables the advisor tool, which consults a second model at key moments.
  • /effortSets the effort level: low to xhigh, max, or auto; status prints it.
  • /fastToggles fast mode (same model, faster output).
