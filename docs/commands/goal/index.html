/goal[condition|clear]

Sets a goal: Claude keeps working across turns until the condition is met or the goal clears. No argument shows the current goal; clear (or stop, off, …) removes it.

Best use

/goal all tests pass, then let it iterate until the suite is green.

Used in these situations

  • Repeat a task or run it on a schedule/loop → /schedule → /goal
