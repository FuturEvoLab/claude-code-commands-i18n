/heapdump

⚿ May expose secrets

Writes a heap snapshot and memory breakdown to the Desktop for diagnosing high memory. Share only the -diagnostics.json; the .heapsnapshot contains your conversation and credentials. Hidden from the menu.

Best use

Report a memory blow-up.

Safety labels

⚿ May expose secrets: Output (files, clipboard, reports) can contain conversation text, keys, passwords or personal data. Review and redact before sharing.
