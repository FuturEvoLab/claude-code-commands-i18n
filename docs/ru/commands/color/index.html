/color[color|default]

англ. color ＝ цвет

Задаёт цвет строки ввода для этой сессии: red, blue, green, yellow, purple, orange, pink или cyan; default сбрасывает, без аргумента выбирается случайный цвет.

Лучшее применение

Отметьте сессию, где вы работаете с продакшеном: /color red.

Похожие команды · Настройки и интерфейс

  • /configОткрывает настройки темы, модели, стиля вывода и другого или сразу задаёт пары key=value, например /config theme=dark.
  • /focusВключает и выключает вид, где видны только ваш последний запрос, однострочная сводка по инструментам и итоговый ответ.
  • /keybindingsОткрывает файл ваших сочетаний клавиш.
  • /scroll-speedНастраивает скорость прокрутки колёсиком мыши.
  • /statuslineНастраивает строку состояния: опишите, что хотите видеть, или запустите без аргументов, чтобы взять её из приглашения вашей оболочки.
  • /terminal-setupВключает Shift+Enter для новой строки в VS Code, Cursor, Devin Desktop, Alacritty или Zed; в Apple Terminal включает Option+Enter и отключает звуковой сигнал; в iTerm2 разрешает доступ к буферу обмена для /copy.
  • /themeМеняет цветовую тему: auto, светлые и тёмные, удобные при дальтонизме, ANSI и собственные темы.
  • /tuiВыбирает способ отрисовки в терминале и перезапускается, сохраняя разговор.
