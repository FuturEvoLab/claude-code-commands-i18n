/remote-control

англ. remote control ＝ удалённое управление

↗ Отправляет данные наружу

Делает эту сессию доступной для Remote Control с claude.ai. Нужна подписка claude.ai.

Лучшее применение

Оставьте задачу работать и управляйте ею с телефона: /rc.

Псевдонимы

/rc

Метки безопасности

↗ Отправляет данные наружу: Отправляет разговор, код или комментарии в другой сервис (Anthropic, GitHub, облачные сессии, сайты в вашем браузере) или отправляет изменения в удалённый репозиторий. Сначала проверьте, что и куда уходит.

Когда пригодится

  • Отойти от компьютера и продолжить с телефона/remote-control → /mobile → /desktop

Похожие команды · Облако, удалённая работа и другие устройства

  • /desktopПродолжает сессию в приложении Claude Code Desktop.
  • /mobileПоказывает QR-код для загрузки мобильного приложения Claude.
  • /remote-envВыбирает облачное окружение по умолчанию для облачных сессий, запущенных из CLI.
  • /setup-bedrockС помощью мастера настраивает авторизацию Amazon Bedrock, регион и закреплённые модели.
  • /setup-vertexС помощью мастера настраивает Agent Platform в Google Cloud.
  • /teleportПереносит облачную сессию в этот терминал, загружая её ветку и разговор.
  • /web-setupПодключает GitHub для облачных сессий с помощью ваших локальных учётных данных gh.
