/install-github-app

англ. install GitHub app ＝ установить приложение GitHub

↗ Отправляет данные наружу⚑ Меняет настройки безопасности

Устанавливает приложение Claude GitHub App для репозитория и по желанию настраивает рабочие процессы GitHub Actions и секреты. Только для github.com.

Лучшее применение

Чтобы упоминать Claude в issues и PR и чтобы он там работал.

Метки безопасности

↗ Отправляет данные наружу: Отправляет разговор, код или комментарии в другой сервис (Anthropic, GitHub, облачные сессии, сайты в вашем браузере) или отправляет изменения в удалённый репозиторий. Сначала проверьте, что и куда уходит.

⚑ Меняет настройки безопасности: Меняет то, что Claude может делать без вопросов, или другие настройки безопасности. Разрешайте только те действия, которые вы понимаете и которым доверяете.

Похожие команды · Плагины, навыки и интеграции

  • /mcpУправлять подключениями внешних инструментов
  • /chromeНастраивает параметры Claude in Chrome.
  • /claude-apiЗагружает справку по Claude API и Managed Agents для языка вашего проекта; включается автоматически, когда код импортирует anthropic.
  • /claude-in-chromeClaude выполняет задачу в вашем браузере через Claude in Chrome, например тестирует страницу или читает журнал консоли.
  • /ideУправляет интеграциями с IDE и показывает их состояние.
  • /install-slack-appУстанавливает приложение Claude для Slack через авторизацию OAuth в браузере.
  • /pluginУправляет плагинами.
  • /plugin-authoringЗагружает справку по написанию мода.
