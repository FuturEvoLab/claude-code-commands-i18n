/import[codex|gemini|cursor] [--dry-run] [--yes]

англ. import ＝ импорт

⇄ Массовые изменения файлов

Импортирует файлы инструкций, серверы MCP, команды, субагентов и навыки из OpenAI Codex, Gemini CLI или Cursor. --dry-run показывает, что будет сделано. Недоступно у некоторых облачных провайдеров; для импорта из Cursor нужна версия v2.1.265+.

Лучшее применение

Переходите с Cursor: сначала /import cursor --dry-run, потом импорт по-настоящему.

Метки безопасности

⇄ Массовые изменения файлов: Может изменить или откатить сразу много файлов. Сначала сделайте коммит или резервную копию, а после проверьте изменения через /diff.

Похожие команды · Проект и файлы

  • /initСоздать CLAUDE.md для проекта
  • /add-dirДобавляет рабочую папку для доступа к файлам в этой сессии, не переходя в неё.
  • /cdПереносит сессию в другую рабочую папку, сохраняя разговор.
  • /diffПоказывает изменения в рабочей копии, включая уже сделанные правки Claude.
  • /insightsСоздаёт HTML-отчёт о ваших недавних сессиях на этом компьютере: проекты, привычки, где возникают проблемы, какие функции стоит попробовать.
  • /team-onboardingАнализирует ваши сессии, команды и использование MCP за последние 30 дней и пишет руководство в Markdown, которое коллега может вставить первым сообщением.
