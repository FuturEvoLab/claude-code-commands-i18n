/sandbox

англ. sandbox ＝ песочница (изолированная среда)

⚑ Меняет настройки безопасности

Включает и выключает режим песочницы, только на поддерживаемых платформах.

Лучшее применение

Включите перед запуском незнакомых скриптов.

Метки безопасности

⚑ Меняет настройки безопасности: Меняет то, что Claude может делать без вопросов, или другие настройки безопасности. Разрешайте только те действия, которые вы понимаете и которым доверяете.

Похожие команды · Разрешения и безопасность

  • /permissionsРешить, что Claude может делать без вопросов
  • /auto-mode-setupСоставляет черновик записей autoMode.environment по вашему проекту и недавним сессиям; вы проверяете и сохраняете.
  • /fewer-permission-promptsПросматривает записи разговоров, находит частые вызовы Bash и MCP только для чтения и добавляет упорядоченный по приоритету список разрешений в .claude/settings.json проекта.
  • /hooksПоказывает настройки хуков.
  • /privacy-settingsПоказывает и изменяет настройки конфиденциальности.
  • /update-configОпишите изменение настроек (разрешить команду, задать переменную окружения, добавить хук), и Claude отредактирует нужный settings.json.
