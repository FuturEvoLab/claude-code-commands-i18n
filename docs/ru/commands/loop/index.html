/loop[interval] [prompt]

Повторять запрос через интервал

англ. loop ＝ цикл, повтор

★ С чего начатьНавык

Повторяет запрос, пока сессия открыта. Без интервала Claude сам выбирает темп; без запроса выполняется встроенный запрос обслуживания или ваш loop.md.

Лучшее применение

/loop 5m проверь, закончился ли деплой. Если запуски должны продолжаться при выключенном компьютере, используйте /schedule.

Псевдонимы

/proactive

Когда пригодится

  • Повторять задачу или запускать её по расписанию/loop → /schedule → /goal
