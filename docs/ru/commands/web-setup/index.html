/web-setup

англ. web setup ＝ настройка веб-версии

Подключает GitHub для облачных сессий с помощью ваших локальных учётных данных gh.

Лучшее применение

Перед первой облачной сессией.

Похожие команды · Облако, удалённая работа и другие устройства

  • /desktopПродолжает сессию в приложении Claude Code Desktop.
  • /mobileПоказывает QR-код для загрузки мобильного приложения Claude.
  • /remote-controlДелает эту сессию доступной для Remote Control с claude.ai.
  • /remote-envВыбирает облачное окружение по умолчанию для облачных сессий, запущенных из CLI.
  • /setup-bedrockС помощью мастера настраивает авторизацию Amazon Bedrock, регион и закреплённые модели.
  • /setup-vertexС помощью мастера настраивает Agent Platform в Google Cloud.
  • /teleportПереносит облачную сессию в этот терминал, загружая её ветку и разговор.
