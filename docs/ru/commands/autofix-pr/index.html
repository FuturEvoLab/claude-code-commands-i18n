/autofix-pr[prompt]

англ. auto-fix PR ＝ автоисправление PR

↗ Отправляет данные наружу

Запускает облачную сессию, которая следит за PR текущей ветки и отправляет исправления при сбоях CI или замечаниях ревьюеров. Нужны CLI gh и облачные сессии.

Лучшее применение

/autofix-pr исправляй только ошибки линтера и типов.

Метки безопасности

↗ Отправляет данные наружу: Отправляет разговор, код или комментарии в другой сервис (Anthropic, GitHub, облачные сессии, сайты в вашем браузере) или отправляет изменения в удалённый репозиторий. Сначала проверьте, что и куда уходит.
