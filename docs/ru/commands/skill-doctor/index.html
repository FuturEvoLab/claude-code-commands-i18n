/skill-doctor

англ. skill doctor ＝ доктор навыков

v2.1.252+

Показывает, сколько контекста занимает каждый навык и как часто он используется, чтобы найти навыки, которые можно выключить.

Лучшее применение

Запускайте время от времени, чтобы убирать неиспользуемые навыки.

Похожие команды · Плагины, навыки и интеграции

  • /mcpУправлять подключениями внешних инструментов
  • /chromeНастраивает параметры Claude in Chrome.
  • /claude-apiЗагружает справку по Claude API и Managed Agents для языка вашего проекта; включается автоматически, когда код импортирует anthropic.
  • /claude-in-chromeClaude выполняет задачу в вашем браузере через Claude in Chrome, например тестирует страницу или читает журнал консоли.
  • /ideУправляет интеграциями с IDE и показывает их состояние.
  • /install-github-appУстанавливает приложение Claude GitHub App для репозитория и по желанию настраивает рабочие процессы GitHub Actions и секреты.
  • /install-slack-appУстанавливает приложение Claude для Slack через авторизацию OAuth в браузере.
  • /pluginУправляет плагинами.
