/model[model]

Сменить модель

англ. model ＝ модель

★ С чего начать

Переключает модель и сохраняет её по умолчанию для новых сессий. Без аргумента открывает список; стрелки влево/вправо меняют уровень усилий на моделях, где это поддерживается; нажмите s на строке, чтобы переключить только для этой сессии.

Лучшее применение

Для мелких правок используйте быструю модель; когда ошибка оказалась сложной, переключитесь: /model opus.

Когда пригодится

  • Увидеть план перед крупным изменением/plan → /effort → /model
  • Тратить меньше денег и лимитов/usage → /model → /effort → /context

Похожие команды · Модель и рассуждения

  • /advisorВключает или выключает инструмент-советник, который в ключевые моменты обращается ко второй модели.
  • /effortЗадаёт уровень усилий: от low до xhigh, max или auto; status показывает текущий.
  • /fastВключает и выключает быстрый режим (та же модель, более быстрый вывод).
  • /output-styleПоказывает список стилей вывода или переключает на один из них, например /output-style concise.
