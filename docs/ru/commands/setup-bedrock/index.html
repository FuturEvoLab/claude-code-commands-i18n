/setup-bedrock

англ. set up Bedrock ＝ настроить Bedrock

С помощью мастера настраивает авторизацию Amazon Bedrock, регион и закреплённые модели. Скрыта в меню, пока не задано CLAUDE_CODE_USE_BEDROCK=1; вводите её полностью.

Лучшее применение

Ваша компания использует Claude через AWS.
