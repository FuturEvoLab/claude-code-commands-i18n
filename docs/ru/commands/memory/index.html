/memory

англ. memory ＝ память

Редактирует файлы памяти CLAUDE.md, включает и выключает автопамять и показывает её записи.

Лучшее применение

Хотите, чтобы все ответы были на вашем языке: откройте /memory и добавьте строку, например «Всегда отвечай по-русски».

Когда пригодится

  • Сделать так, чтобы Claude всегда отвечал на моём языке/init → /memory

Похожие команды · Разговор и контекст

  • /clearНачать новый разговор (старый можно вернуть)
  • /compactСжать длинный разговор, чтобы освободить место
  • /contextПосмотреть, чем заполнен контекст
  • /planСначала план; правки ждут вашего одобрения
  • /resumeВернуться к прежнему разговору
  • /rewindОтмена: откатить код и разговор
  • /autocompactЗадаёт, насколько должно заполниться окно контекста перед автоматическим сжатием, например 500k; auto возвращает значение по умолчанию, подобранное для модели.
  • /branchСоздаёт ответвление разговора с этого места и переключается в него; исходный разговор сохраняется и доступен через /resume.
