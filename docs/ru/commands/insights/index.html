/insights

англ. insights ＝ выводы, аналитика

Создаёт HTML-отчёт о ваших недавних сессиях на этом компьютере: проекты, привычки, где возникают проблемы, какие функции стоит попробовать. Недоступно в облачных сессиях.

Лучшее применение

Через несколько недель запустите /insights, чтобы найти функции, которые вы ещё не пробовали.

Когда пригодится

  • Как следует изучить Claude Code/powerup → /help → /insights

Похожие команды · Проект и файлы

  • /initСоздать CLAUDE.md для проекта
  • /add-dirДобавляет рабочую папку для доступа к файлам в этой сессии, не переходя в неё.
  • /cdПереносит сессию в другую рабочую папку, сохраняя разговор.
  • /diffПоказывает изменения в рабочей копии, включая уже сделанные правки Claude.
  • /importИмпортирует файлы инструкций, серверы MCP, команды, субагентов и навыки из OpenAI Codex, Gemini CLI или Cursor.
  • /team-onboardingАнализирует ваши сессии, команды и использование MCP за последние 30 дней и пишет руководство в Markdown, которое коллега может вставить первым сообщением.
